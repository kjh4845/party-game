# R20 B 잡기 — 어깨 변형 보완과 낮은 래그돌 잡기

후속 2026-09-17: 사용자가 부분 중력 보조 들기를 승인해 [들기·해제 던지기 별도 후보](R20_LIMP_LIFT_ASSIST_20260917.md)를 추가했다. 아래 기록은 9월16일 잡기·끌기 검증 이력이다. 이후 사용자가 들기 체감을 승인하고 다음 진행을 요청해 [접촉면 보완 후보](R20_SKIN_CONTACT_CANDIDATE_20260917.md)를 검토한다.

상태: **어깨 피부 검사 통과 / 낮은 잡기·끌기 기능 구현 / 손과 피부 사이 간격 보완 필요.** 사용자는 B 거리·높이 반응형을 선택한 뒤 후속 진행을 지시했다. 별도 후보에서 어깨 변형을 보완하고 실제 래그돌의 낮은 접점을 잡는 과정을 검토했다. 전체2단계 완료나3단계 착수로 표시하지 않는다.

## 어깨 보완

원래 메쉬 좌표·면·노멀, 기존22개 뼈의 정의와 머리/하체 가중치를 보존했다. 어깨의 피부 변형에만 사용하는 `ShoulderBlend_L/R` 두 뼈를 추가한24-bone 후보이며 물리 몸체를 추가한 것은 아니다. 기존 master r20의 정식 Rig Gate를 새 후보로 교체하지 않는다.

몸통과 위팔 회전의 중간을 보조 뼈가 따라가고, 어깨 영역의 가중치를 이 보조 뼈로 분산한다. 기존4개 영향 수를 유지하기 위해 이 검토에서 Chest와 같은 변형을 하는 해당 영역의 Clavicle/Neck 가중치를 Chest로 합친 뒤 배분한다. 매 프레임 전체 메쉬를 CPU에서 보정하는 방식은 사용하지 않는다. 보조 뼈는 물리 후 고정 snapshot에 포함되고 렌더에서 함께 보간되며, 물리에 자세 복원력을 추가하지 않는다.

- 변경 가중치 정점55,492/227,942개, 영역 밖·하체 가중치 동일, 최대4개 영향.
- 좌우 가중치 차이 최대 약0.000000507, 합계 오차 약0.000000179.
- 같은 물리 설정으로 피부만 바꾼 검사는 모든 고정 tick의 물리 위치 차이0 및 잡기 상태 일치를 확인했다. 아래 접촉용 손끝 보정은 이 피부 단독 비교와 별도의 물리 형상 변경이다.

|---|---:|---:|
| 뻗기·높이 변화 | 179.91도 | 16.57도 |
| 한손 당김 | 134.17도 | 21.70도 |
| 양손 당김 | 179.98도 | 20.92도 |

수치는 인접한 피부 삼각형의 각도이며 팔 관절각이 아니다. 영상 전체 고정 tick에서60도 미만 기준을 통과했다. 모든 메쉬 자체 교차나 향후 펀치/회복 자세까지 보증하는 검사는 아니다. 기존 펀치·회복 자산은 그대로 보존했고, 새 능동형 물리 구현의 해당 동작 통합은 후속이다.

## 낮은 접점과 래그돌

잡는 캐릭터가 실제 접점 높이에 맞춰 골반과 상체를 함께 숙인다. 골반 하강은 최대25mm, 전방 기울임은 골반/Spine24.5도와 Chest 추가10.5도로 나눈다. 발은 기존 하체 해석으로 접지를 유지하고, 물리 Spine 연결점도 골반 숙임을 함께 따라가 허리 피부가 따로 꺾이지 않게 했다. 입력 이동과 버튼 해제는 자세 완료를 기다리지 않는다.

대상은 기존 분할 래그돌의 실제12개 동적 몸체·20kg을 사용하는 **영구 넉다운 검토용 대상**이다. 활성 각도 drive의 spring/damper/force는0이다. 동작 clip이나 일어나기 처리 없이 물리에 맡기며, 관절 연결·회전 한도·일반 감쇠는 유지한다. 실제 게임의 누적 피해→Down 전환·회복 타이머·잡은 상태 회복 통합 완료가 아니다.

손끝 메쉬가 기존 충돌체보다 약12.23mm 길어, 별도 보완 장면에는16mm의 끝부분 보정을 적용했다. 누운 몸통에는 실제 폭/깊이를 반영한 작은 convex hull을 시험했고, 해당 대상의 기존 자기 충돌 제외 관계를 유지했다. 원래 기본 Shared Arena와 승인된B 진입 메뉴의 모델은 자동 교체하지 않았다.

네 초기 방향 모두 실제 양손 획득을 관측했고, 대상은 검토 입력에서 약0.34~0.43m 이동했다. 해제 후 남은 연결0, 대상 회복0이다. 촬영 전체에서 잡는 쪽 피부 꺾임 최대35.84도, 누운 쪽 최대22.39도였다.

## 아직 해결되지 않은 접점

실제 손 정점과 변형된 대상 메쉬를 BVH로 비교한16개 유지/당김 접점 표본에서는 관통0을 측정했다. 하지만 손 정점과 피부의 최소 거리가 일부 표본에서 **최대 약36.25mm** 남았다. 전체 충돌체를 넉넉히 맞추는 것으로는 변형되는 피부와의 밀착을 동시에 만족시키지 못했다.

이는 해결 완료가 아니다. 기능·피부 꺾임 테스트 통과와 손 밀착 품질을 구분한다. 이 측정은 특정16개 표본이고 모든 프레임/전 부위의 무관통을 증명하지 않는다.3단계 펀치·던지기로 넘어가기 전에 접점을 보완하거나 사용자가 이 한계를 명시적으로 선택해야 한다.

제안하는 다음 작업은 손 주변에만 실제 피부를 따르는 작은 물리 접촉면을 추가하는 별도 후보다. 넓은 몸통 충돌체를 계속 키우는 대신, 고정 물리 상태에서 피부 표면과 법선을 계산하고 손 접촉을 처리한다. 피부의 같은 지점을 잡은 상태로 추적하고, 부위별 물리 몸체에 힘을 전달해야 한다. 다음 항목을 검증해야 한다.

- [ ] 손/전완의 실제 표면 접촉과 유지 중 밀착, 무입력/해제 때 부자연스러운 밀어냄 방지.
- [ ] 기존 본인 손별 해제·타인 소유권·하중 피로·즉시 조작 규칙 유지.
- [ ] 래그돌의 자세 drive0·총질량20kg 유지, 추가 접촉면에 의한 자기 충돌/질량 변화 방지.
- [ ] Render 보간과 분리한60Hz 연산,15/60/144FPS 재생 및 비용 검증.

이 추가 접촉 방식은 아직 구현하지 않았고 사용자에게 진행 여부를 물었다.

검증: 최종 PlayMode8/8, 별도의 피부/물리 동일성 검사1/1, EditMode140/140, 문서 워크플로 검사7/7과 기준 검증 통과. 낮은 잡기15/60/144FPS 위치 차이0, Reset/재입력/기본 PlayerLoop를 확인했다. 기능 검사 통과가 위 손 밀착 문제의 해결을 의미하지 않는다. Player Build·commit·push0.
