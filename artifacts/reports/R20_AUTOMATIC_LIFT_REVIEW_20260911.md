# R20 자동 상향 들기와 상호 잡기 차단 — 2026-09-11

상태: **사용자 승인 규칙을 로컬 시제품에 연결**. 사용자는 위쪽으로 팔을 올리는 잡기를 승인하면서 서로 잡은 상태에서는 서로 들리지 않도록 요청했다. 기본 `Open Shared Arena 2/3/4 Players`와 `Open Ledge Recovery Review`에 적용한다. 정식 캐릭터/맵/멀티플레이 Gate 완료를 뜻하지 않는다.

## 동작 규칙

| 상황 | 처리 |
|---|---|
| A만 B를 잡음 | 클릭 유지 중 접촉 목표를 점차 올려 B도 실제 물리로 들린다. |
| A가 B를 잡고 B도 A를 잡음 | 해당 쌍의 양쪽 자동 들기를 차단한다. 어느 손인지, 한손/양손인지와 무관하다. |
| 들리는 도중 되잡음 | 이미 진행한 목표 위치에서 추가 상승을 멈춘다. 역방향 joint가 생긴 순간 강제로 위치를 내리거나 순간 이동시키지 않는다. |
| 상호 잡기가 풀림 | 남아 있는 유효한 한쪽 잡기는 현재 진행도에서 들기를 이어간다. |
| 같은 대상의 양손 중 하나 해제 | 나머지 손으로 유지한다. |
| 마지막 본인 손 해제 | 들기 완료 여부와 무관하게 즉시 기존 bounded Throw를 한 번 적용한다. |
| 메뉴·주체 Down·Reset·손/대상 상실 | 자동 들기를 중단하고 기존 강제 해제 경로를 사용한다. 추가 던지기0회다. |
| 정적 벽 | 높은 실제 접촉점을 잡으며 맵을 들어 올리지 않는다. 기존 하중 자세와 제한된 Space 복귀를 연결한다. |

상호 차단은 A↔B의 실제 접촉 관계를 기준으로 한다. 단순히 다른 사람이 잡고 있다는 이유로 모든 자동 들기를 막는 전역 상태가 아니다. 이미 존재하는 중력·관성·외부 충격이나 사용자가 직접 하는 점프를 제거하는 규칙도 아니다.

## 구현 경계와 START 수치

- 자동 들기는 접촉 후0.65초 동안 최대0.30CU 위,0.10CU 안쪽으로 이동한다. SmoothStep으로 시작과 끝을 완화한다. 양손 동일 대상은 중복 이동하지 않는다.
- 모든 플레이어의 손 입력/접촉 생성·해제를 처리한 뒤, 물리 시뮬레이션 전에 상호 관계를 검사한다. 같은 tick의 처리 순서에 따라 한쪽이 먼저 들리는 일을 막고 한 tick에 한 번만 갱신한다.
- 실제 joint가 상대 질량과 중력을 받으며 기존 force/GripStress 경로를 유지한다. 상대의 현재 동적 collider들을 검사해 천장/외부 장애물 쪽으로 들기 목표를 더 밀지 않는다. Down에서는12개 몸체의 실제 접촉과 총 질량20kg을 사용한다.
- 들기와 손 표현을 분리한다. 어깨 회전량은 실제 접촉 높이를 읽으며 몸통 앞에서 위쪽으로 올라간다. 팔 길이와 원본 모델/rig/weight는 바꾸지 않는다.
- 벽은 루트 기준0.82CU 높이의 실제 정적 표면 접촉을 찾는다. 손 후보의 근접/가림 검사와 실제 고정 시점 팔 길이 검사를 유지한다. 높은 접촉의 유지 보조 거리 상한은0.415CU이며 실제 팔 도달 검사가 함께 제한한다.
- 높은 벽 접촉을 획득한 바로 그 물리 tick부터 기존 상한 내 지지력을 적용한다. 빠른 하강에서 한 프레임 늦게 지지해 손 범위를 지나치는 문제를 막는다.
- Space 상승 중 접촉 높이가 루트 기준0.74CU 아래로 내려오면 손을 해제하고 공중 이동으로 넘긴다. 몸이 손에 너무 가까워져 팔꿈치를 과하게 접는 구간을 없앤다. 공중당 보조2회/350ms와 기존 최대 상승량1.25CU는 유지한다.
- Throw30N·s/추가 속도 상한3m/s, 마지막 손 release, 피격 누적과 일반 투척 충돌 피해0은 유지한다. 들기를 기다려야 던질 수 있는 새 준비 조건은 없다.

최신 기본 장면은 새 프로필을 사용한다. 과거 Grab/Release/Ledge 독립 회귀 검사는 기존 수치를 명시적으로 사용해 이전 동작과의 비교 기록을 유지한다.

## 확인 방법

1. 기본 Shared Arena를 열고 상대에게 가까이 가서 한 손 또는 양손 클릭을 유지한다. 실제 상대가 올라가는지 본다.
2. 양쪽 플레이어가 서로를 잡으면 둘 다 자동 상승하지 않는지 본다. 되잡기가 생기거나 풀릴 때 순간적인 위치 튐이 없는지 확인한다.
3. 양손 중 하나를 놓은 뒤 마지막 손을 놓는다. 들기 진행 중에도 마지막 손 해제는 즉시 던지기여야 한다.
4. 벽에서는 위쪽 접촉을 잡고 Space로 복귀한다. 메뉴·Down·Reset도 확인한다.

자동 검사는 실제 접촉과 입력 큐를 사용한다. 한쪽 들기는 약0.30m의 실제 상승, 즉시 release, 양손 중복 방지, 상호 잡기 처리 순서, 되잡기와 재개, 천장, Down/12몸체, 메뉴/Reset,15/60/144FPS, Unity 기본 FixedUpdate 실행 순서를 포함한다. 벽은4방향×3깊이에서 모두 높은 접촉과2회 이내 복귀를 확인했다.

실제 사람 들기/해제와 상호 잡기 표면 각 최댓값은 약43.47도, 높은 벽 잡기/복귀는 약44.65도였다. 측정한 held 손 오차는0.001mm 미만이다. 표면 각 측정은 전체 자체 교차 검사를 대신하지 않는다.
