# 광배·옆구리 가중치 조정 후보

사용자 요청: 펀치 때 팔을 따라 끌려가는 광배 부근을 조정한다. 현재 펀치0.5초와 부위별 피격 점수/넉다운 정책은 변경하지 않는다.

## 변경 범위

- 승인된 하체 가중치 후보를 원본으로 사용해 별도 Blender 후보를 생성한다.
- 몸통 옆면의 `Clavicle_L/R`, `UpperArm_L/R` 영향 일부를 이미 존재하는 `Spine`, `Chest` 가중치로 옮긴다.
- 겨드랑이/상완 연결부는 보존하고, 안쪽 몸통으로 갈수록 보정량을 늘린다. 좌우를 같은 규칙으로 조정한다.
- 머리, 하체 가중치, 메쉬 정점/면/연결, 뼈 위치·계층, 승인된 펀치 곡선은 보존한다. 최대4개 영향과 정규화 합1을 유지한다.
- 새 transport는 기존 geometry/bind/header bones를 재사용하고 수정 정점의 body 가중치/인덱스만 교체한다. 수정되지 않은 정점의 슬롯 bytes도 보존한다.

## 후보 선택

넓은 영역을 일괄 보정한 r01/r02는 겨드랑이 접힘/자기 교차 때문에 제외했다. 연결부의 가중치를 보존한 r03/r04/r05는 Blender 검사에 통과했지만, Unity의 실제 양손 잡기에서 r05가60.998도로 접혀 제외했다. 강도만 낮춘 r06도47.699도로 기준45도를 넘었다.

최종 r07은 몸통 아래쪽의 보정은 유지하면서, 높이0.48~0.64m의 어깨 연결부로 갈수록 보정이 사라지도록 바꿨다. 실제 Unity 잡기에서 기록한 뼈 자세로 경계를 비교한 뒤 선정했다. 미수정 정점의 transport 슬롯도 그대로 보존한다.

## Blender 측정

| 구역 | 기존 평균 움직임 | 수정 평균 움직임 | 기존 최대 | 수정 최대 |
|---|---:|---:|---:|---:|
| 옆등 | 2.659cm | 1.088cm | 7.726cm | 4.944cm |
| 겨드랑이 위쪽 뒤면 | 2.550cm | 1.694cm | 7.783cm | 5.064cm |

선택한 펀치4개 자세와 해당 영역의 동일 정점을 비교한 결과다. 옆등 평균은 약59% 감소했다. 어깨와 직접 이어지는 경계까지 고정하는 수정은 아니다.

좌우 펀치14자세, 걷기/뛰기8자세, 잡기/벽 짚기6자세 총28자세가45도 이상 날카로운 접힘/90도 이상 뒤집힘 검사에 통과했다. 이 중 양손 잡기·벽 짚기와 좌우 펀치 준비/최대 뻗기6자세는 비인접 면 자기 교차도 검사했다.

## Unity 연결

`Project Hotfix > Prototypes > Open Lat Weight Candidate`에서 새 후보를 연다. 기존 `Open Articulated Punch Candidate`는 비교를 위해 기존 가중치를 유지한다. 후보는 같은0.5초 펀치와 몸통·팔다리1점/머리2점, 기준10→6점 규칙을 사용한다.

원본 source와 승인 transport는 교체하지 않았다. 비교 영상과 Unity 표면/회복 검증 결과는 [구조화 기록](R20_LAT_WEIGHT_ADJUSTMENT_20260909.json)에 보존한다. 사람의 최종 외형 확인, 실제 다인/peer/성능 검증은 별도다.

## 최종 검증

- Unity 후보3/3: 순수 가중치/동기 펀치 비교, 실제 정밀 Hit10회→Down→다음 기준9점, 걷기·뛰기·양손 잡기·앞/뒤/좌/우 회복.
- 펀치 비교 최대 표면 각23.383도, 뼈 회전 차이0도. 회귀 표면 각은 걷기42.659도, 뛰기41.788도, 양손 잡기40.422도, 네 방향 회복30.870도 이하로 모두45도 미만이다.
- 기존 빠른 펀치 검사5/5, 전체 EditMode125/125, 문서 기준 PASS, workflow7/7, 생성기 문법 검사와 `git diff --check` 통과.
- 승인 transport와 비교해 뼈/계층, body 정점·normal·triangle bytes, head 전체 bytes 일치. 원본 Blender·GetUp·펀치 library hash도 일치한다.
- 앞/뒤 비교는 같은0.5초 펀치를 같은 시각에 실행한다. 흰색=기존, 주황색=수정.30fps 정상 속도, 마지막 프레임1초 유지.
