# R20 상향 잡기 자세 검토 — 2026-09-11

상태: **리그 도달 검토 완료 / 후속 구현 승인**. 사용자가 자동 들기를 승인하고 서로 잡으면 서로 들리지 않도록 요청했다. 이 문서는 최초 자세 검토 기록이며 최신 연결은 [자동 들기 검토](R20_AUTOMATIC_LIFT_REVIEW_20260911.md)를 따른다.

## 권장 방향

- 사람: 손을 앞쪽 접촉점에서 대각선 위로 옮기며 상대도 물리적으로 들어 올린다. 손만 위로 움직여 접촉을 끊어 보이게 하지 않는다.
- 벽: 위쪽의 실제 닿는 표면을 찾아 잡는다. 맵을 끌어올리는 들기와 구분하며, 기존 한손/양손 하중 자세와 Space 복귀를 연결한다.
- 조작: 별도 들기 버튼이나 들기 완료 조건을 추가하지 않는다. 허용한다면 클릭을 유지하는 동안 점차 올리고, 마지막 손을 놓는 즉시 기존 던지기를 실행한다. 짧게 잡고 바로 놓아도 기다리지 않는다.

초기 문서에는 자동 들기를 사용하지 않는다고 기록돼 있었다. 사용자 후속 답변으로 자동 들기와 상호 잡기 차단이 승인됐다.

## 현재 리그에서 확인한 것

현재 r07 가중치 리그로 같은 팔 길이와 손 끝을 사용해 좌우 양팔의 도달·표면 변형을 검사했다. 모델·리그·weight 원본을 수정하지 않았다.

| 접촉 높이 / 앞쪽 거리(CU) | 기존 어깨 설정의 표면 각 | 어깨를 함께 회전한 설정의 표면 각 |
|---|---:|---:|
| 0.54 / 0.32 | 41.59° | 27.79° |
| 0.72 / 0.27 | 84.02° | 29.94° |
| 0.84 / 0.22 | 179.42° | 19.41° |
| 0.90 / 0.18 | 179.15° | 20.87° |

숫자는 준비 자세부터 목표까지 샘플링한 몸체의 인접 삼각형 각 최댓값이다. 기존 독립 Lift 검토에 있는 어깨 회전 설정을 사용하면 높은 목표에서도 겨드랑이의 심한 접힘을 피할 수 있었다.8조건 모두 최종 손 끝 오차는0.001mm 미만이었다. 전체 자체 교차나 실제 캐릭터 들기/벽 복귀 물리의 완료를 뜻하지 않는다.

## 선택 후 구현 체크리스트

- 위쪽 도달 범위와 실제 표면의 가림/접촉을 검사하고 자동 흡착 범위를 넓히지 않는다.
- 사람을 들어 올리는 경우 질량·하중 피로, 천장과 벽·다른 캐릭터, 다른 플레이어의 잡기 저항을 함께 확인한다.
- 한손/양손 전환과 잡은 상대의 Down/GetUp에서 접촉을 보존한다.
- 마지막 손 release의 즉시 던지기·중복0회와 강제 해제 시 던지기0회를 유지한다.
- 15/60/144FPS 동작 일치, 손 접촉, 어깨/팔꿈치 변형과 복귀 연결을 검증한 뒤 실제 물리 비교 영상을 만든다.
