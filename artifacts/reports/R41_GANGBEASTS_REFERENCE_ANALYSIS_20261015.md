## 1. 싸움 흐름(영상 실측)

| 관찰 | 근거 구간 | 수치 |
|---|---|---|
| 팔을 끝까지 뻗는 시간 | 2.12~2.20s(초록), 2.03~2.12s(노랑) | 약 4~6프레임 = **0.07~0.10초** |
| 두 사람의 교대 타격 간격 | 2.12~2.45s에 팔 뻗기 약 4회 | **약 0.08~0.15초**마다 누군가 친다 |
| 거리 | 0~1.3s, 1.9~2.6s | 몸이 거의 닿는 근접(몸통 하나 이내). 붙잡기와 섞인다 |
| 맞을 때 반응 | 2.25~2.35s 노랑 | 크게 밀리지 않는다. **상체가 뒤로 휘청**이고 바로 다시 친다 |
| 결정타 | 2.53~2.70s, 11.0~11.3s | 몸 전체로 덮치거나 휘두른 한 방에 **바로 대(大)자로 쓰러짐(기절)**. 수 초 동안 누워 있다 |
| 승부 | 7~9s, 15~17s, 22~36s | 기절한 상대를 **잡아 끌고 가 난간·벽 너머로 던지거나 떨어뜨림**. 매달리기·끌어내리기로 역전 |

해석:
- 펀치 하나하나는 정교하지 않다. 팔은 흐물거리는 관이고 궤적이 매번 다르다. 재미는 빠른 교대 타격, 상체 휘청임, 누적 후 갑작스러운 기절에서 나온다.
- 펀치는 승부를 내는 수단이 아니라 **기절→잡기→던지기**로 가는 준비 동작이다.
- 조작은 자료로 확인했다. 한 손에 버튼 하나이고, 누르면 펀치, 유지하면 잡기, 잡고 움직이다 놓으면 던지기다.
