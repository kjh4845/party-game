## 구현한 범위

1. **실제 접촉으로 획득한다.** 150ms 유지 후 실제 전완 끝 충돌의 접점을 확인한다. 손끝55mm 이내 접촉만 후보이며 다음 고정 tick에60mm 이내인지 다시 확인한다. 멀리 있는 상대를 검색해 손을 순간이동시키는 방식이 아니다.
2. **손마다 실제 물리 연결과 소유권이 있다.** 같은 손 접촉을 서로 잡으면 하나의 연결을 공유한다. 양쪽 총4개의 잡기 입력이2개의 물리 연결을 소유할 수 있다. 내 손을 놓아도 상대 소유의 잡기는 남는다.
3. **손 부피를 유지하며 굴러 움직이게 한다.** 둥근 전완 끝의 중심 간 허용 간격을 두어 접촉 충돌과 잡기 구속이 서로 싸우지 않게 했다. 각도는 자유이며 상대와의 충돌은 유지한다. 손잡이의 위치를 고정하는 IK는 없다.
4. **붙잡는 순간의 팔 자세를 힘의 기준으로 사용한다.** 위팔·전완 관절 구동은 기존의65%로 따라가고, 접촉·중력·외력에 의해 실제 팔이 움직인다. 신체 위치를 고정하거나 상대를 기계적으로 밀어내는 보정은 없다.
5. **이동 힘은 전체20kg을 기준으로 전달한다.** 상체를 포함한 운동량과 회전 관성을 사용한다. 이동 설정은 걷기1.40/달리기2.10m/s·가속도20m/s²를 유지한다. 이 검토실의 약한 무입력 제동은 상대가 끌려갈 수 있도록 한다. 하체 보행은 물리 속도에 따라 표시한다.
6. **피로는 실제 하중에서만 누적한다.** 관절 힘/250N을 기존 GripStress에 입력한다. 입력 해제·피로·접점 이탈·대상 소실·메뉴·Reset을 구분하고, 강제로 놓친 뒤에는 계속 누른 버튼으로 자동 재획득하지 않는다.

이 장면은 자동 들기·던지기·점프·타격·피해·Down/GetUp을 아직 연결하지 않았다. 상호 잡기 중 상승하지 않는 것은 확인했지만, 새 자동 들기 기능의 상호 차단 통합은3단계에서 검증해야 한다. 기존 Shared Arena의 승인된 즉시 던지기·상호 들기 차단·넉다운 규칙은 그대로다.

## 물리와 표현 설정

현재 모델/리그/r07 가중치, 캐릭터당8개 물리 몸체·7개 관절·20kg을 사용한다. Stage2에만 solver48/16, Spine/Chest 반경0.15m, 어깨 관절 X −25~100도/YZ15도, 지상 마찰0.25/0.15를 적용한다. joint projection은 사용하지 않는다. 렌더는 고정 snapshot 보간이며 표시용 뼈가 다음 물리 입력으로 되돌아가지 않는다. 피부는 원래 뼈 길이를 유지하고 물리 회전을 따라가므로 solver의 미세한 접점 오차만큼 표시와 물리 뼈 위치가 다를 수 있다.

## 검증과 한계

- PlayMode **17건 중16건 통과,1건 실패**. 실제 획득·독립 소유권·입력 처리 순서·개별 놓기·끌기·메뉴/Reset·대상 소실·FPS 독립성·기본 PlayerLoop와 Stage1/기존 상호 들기 차단 회귀를 확인했다.
- 실패는 `CapturePhysicalGrabsAndSkin`의 양손 당김이다. 표면 인접 삼각형 각도 최대179.824도로 검사 기준60도를 넘었다. 한손40.407도, 상호 잡기40.305도다. 이 각도는 국소 피부 접힘 검사이며 팔 관절 회전각이 아니다.
- 세 영상 모두 실제 잡기 획득이 있었고 마지막 입력 해제 후 남은 연결0개다. 허용 간격을 넘는 최대 연결 오차는 한손0.57mm·양손3.92mm·상호1.81mm다. 이는 충돌체·스킨 관통 전체의 최댓값을 뜻하지 않는다.
- 상호 잡기10초 무입력 유지: 잡기4개 유지·피로0. 양쪽 이동 몸체에 지속240N 하중을 가한 별도 검사: 피로0.99999까지 관측한 뒤 실제 GripStress 해제, 최대 연결 오차4.44mm.
- 최초 급격한 최대속도 반대 입력 검사는 피로보다 접점 이탈 안전 한도가 먼저 작동했다. 이를 피로 검증 성공으로 계산하지 않았다. 지속 하중 검사로 피로에 의한 해제를 별도로 검증했다. 강한 입력의 접점 이탈 빈도는 후속 체감 조정 대상이다.
- 15/60/144FPS 일정에서 동일한240회 고정 입력의 물리 위치 차이0, 잡기 상태 일치. 이것은 동일 환경 재생 검사이며 네트워크 peer 간 결정론 보장이 아니다.
- EditMode140/140 통과. 원본 기준 자산9개의 SHA-256 일치. Player Build·commit·push0.

어깨 회전 범위 축소, 쇄골 물리 구동, 국소 가중치 평활화/재분배와 간단한 형태 보정 시험은 강한 하중의 스킨 기준을 충족하지 못했다. 실패한 가중치·형태 후보는 임시 검토 폴더에만 있고 현재 Unity 모델에는 적용하지 않았다. 전체 피부 자체 교차와 모든 신체 부위 간 스킨 관통이 해결됐다고 판단하지 않는다.
