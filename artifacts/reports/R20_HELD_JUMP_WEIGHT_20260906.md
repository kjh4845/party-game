# 잡은 상태 점프 — 무게감 유지 조정

사용자가 상대의 무게를 고려해 혼자 점프할 때보다 낮게 올라가도록 요청했다.
직전100% 보정은 같은 체급 상대의 무게를 사실상 상쇄했다. 현재 기본값은 **75% 부분 보정**이다.
중력·질량·혼자 점프 설정을 바꾸지 않고, 잡은 대상에 제공하는 추가 상승분만 줄였다.

## 실제 높이

20kg 조작 캐릭터의 평지 PhysicsRoot 상승 높이다. 상대는 별도 점프 입력 없이 잡혀 있는 물리 표적이다.

| 조건 | 상승 높이 |
|---|---:|
| 혼자 | 약23.19cm |
| 같은 체급 상대, 무보정 | 약5.35cm |
| 같은 체급 상대, 직전100% 보정 | 약23.19cm |
| 같은 체급 상대 한 명, 현재75% 보정 | 약17.54cm |
| 같은 상대를 양손으로 잡기 | 약17.54cm |
| 서로 다른20kg 상대 둘 잡기 | 약15.85cm |
| 100kg 대상, 지원 상한 적용 | 약3.60cm |

같은 체급 한 명을 잡은 높이는 solo의 약76%다. 대상이 추가되거나 더 무거워지면 더 낮게 올라간다.
단, **두 캐릭터가 각자 점프를 입력하면** 각자의 힘으로 뛰므로 이번 검사에서는 solo 높이를 유지했다.
수동 상대를 한 사람이 들어 올리는 조건과 구분한다. 동시 점프의 처리 순서를 바꿔도 높이 중첩은 없었다.

## 변경

- `HeldJumpAssistance` 기본값을1→0.75로 조정했다.
- 운동량 예산뿐 아니라 대상별 지원 비율도0.75 이내로 제한한다.
  예산만 줄이면 가벼운 대상에게 여전히100% 보정이 들어갈 수 있어, 두 제한을 함께 적용한다.
- 동일 Rigidbody의 양손 중복 제거, jump당1회, 해제/무효 대상 제외, 상승분·추가 운동량 상한은 유지한다.
- 중력9.81m/s², 기본 JumpHeight0.25m, Walk0.70/Sprint1.05m/s,20kg 검토 몸체와 기존 그립 피로 정책은 유지한다.

75%는 프로토타입 시작값이며 최종 전투 재미/밸런스의 승인값은 아니다.
무거운 대상·낙하 속도·외부 충격·여러 사람이 연결된 조건에 따라 실제 높이는 달라질 수 있다.

## 검증과 사용

전용24조건에서 solo와의 높이 차이, 대상 수/질량별 높이 순서, 양손 중복,8방향,
해제·무효 대상·공중 재요청·재점프·Reset·동시/서로 잡은 점프를 검사했다.
기존 Grab 물리·표면 및 Jump 전환을 포함한 전체 EditMode96/96·PlayMode26/26이 통과했다.
자연스러움의 모든 상황 보장이나 실제 peer 플레이테스트 완료를 뜻하지 않는다.

`Project Hotfix → Prototypes → Open Grab Physics Review`에서 현재 부분 보정으로 확인할 수 있다.
영상은 왼쪽 solo, 가운데 직전100% 보정, 오른쪽 현재 무게감 반영이다.
