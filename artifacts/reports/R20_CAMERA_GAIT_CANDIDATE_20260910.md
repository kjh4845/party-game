# 공용 카메라 보행·달리기 — 채택 기준

이 기록은 보행 모양 승인 당시의 비교다. 현재 Shared Arena의 이동 속도·주기·발 들림은 후속 [2배 속도 승인](R20_MOVEMENT_SPEED_REVIEW_20260910.md)을 따른다.

사용자 요청: 공용 카메라에서 보행이 잘게 떨리고 미끄러지는 듯한 인상을 개선한다. 실제 이동 속도와 기존 모델·리그·광배/하체 가중치는 유지하고, 같은 구도의60fps 영상으로 비교한다.

## 후보 설정

| 항목 | 기존 | 후보 |
|---|---:|---:|
| Walk/Sprint 이동 속도 | 0.70 / 1.05m/s | 동일 |
| 한쪽 발의 주기 | 3.0 / 4.5Hz | 2.4 / 3.6Hz |
| 양발 교대 빈도(정속) | 6 / 9회/s | 4.8 / 7.2회/s |
| 발 들림 목표 | 1.0cm | 1.8cm |
| 골반 내림 | 2.0~2.2cm | 1.0~2.4cm |
| 골반 좌우 이동/roll | 기존값 | 60% |
| 자유로운 팔 swing | 기존값 | 75% |

실제 발 들림과 보폭은 리그·발 접지 결과에서 따로 측정한다. 더 느린3.0/3.2/3.4Hz 달리기와 비대칭 지지 시간은 다리/발 주변 표면 검사를 통과하지 못해 제외했다. 발을 뻗어 딛는 구간에는 골반을 낮추고, 발을 들어 옮기는 구간에는 올려 짧은 다리의 도달 여유를 확보한다.

## 연결 처리

- 출발 시 보폭이 가속에 맞춰 커지도록 activation을 늦게 완성해 목표점의 과도한 도달 보정을 줄인다.
- 급회전 중에는 시선과 실제 진행 방향이 어긋난 정도에 따라 보폭을 최대35% 줄인다. 안정된 정속 지지 때만 발을 고정하며, 회전·가속·점프에서는 기존처럼 접지 고정을 푼다.
- 공중의 tuck과 골반 내림이 합쳐져 과도하게 굽지 않도록 후보에서 combined shortening을 제한한다. 점프 물리, 속도, buffer/coyote와 방향 입력은 변경하지 않는다.
- 후보의 화면용/판정용 보행은 동일한 물리 step의 상태 표본을 사용한다. 화면에 그려진 bone을 읽어 Hit를 만들지 않는다.
- 넉다운 회복 뒤에는 후보의 오래된 달리기/발 접지 상태를 지운다. 판정용 뼈도 물리 표현의 topology 변경을 감지해 같은 기준으로 초기화한다. 점프 착지 중 gait phase는 재시작하지 않는다.
- 펀치0.5초, 몸통·팔다리1점/머리2점, 넉다운 기준10→6점과 대기 시간 증가는 유지한다.

## 검증과 영상

정속 보행은8방향×걷기/달리기×기존/후보32조건에서 같은 Root 속도로 실행한다. 지지 중 발의 월드 속도·접지 유지 비율, 발 높이·보폭, 골반 이동, 도달 보정, 바닥 침범과 표면 각을 측정한다. 별도로8방향 출발·점프·공중 방향 전환·착지·정지·재출발, 펀치 조합, 넉다운 후 복귀와 판정용 pose 일치를 검사한다.

4인 영상은 동일한 시차 입력(걷기→정지→달리기→정지)과 동일한 공용 카메라에서 매 physics step마다 실제 새 render frame을 캡처한다. 기존/후보의 매 Root 위치와 카메라 위치 차이가0.1mm 미만인지 검사한다. frame 보간이나20fps frame 복제로60fps를 만들지 않는다. MP4는 타임스탬프·명목 fps·decode frame 수와 서로 다른 frame 수를 검증한다.

## 실행

`Project Hotfix > Prototypes > Open Shared Arena 2/3/4 Players`에서 채택된 보행을 연다. `Open Previous Shared Gait 2/3/4 Players`는 이전 보행 비교를 제공한다. F1~F4 조작 대상, WASD 이동, Shift 달리기, Space 점프, 좌/우 클릭·유지, Esc 입력 메뉴, R 초기화, F8 도움말은 동일하다.

2026-09-10 사용자가 “보여줬던 영상에서 후보로 바꾸자 그게 훨씬 자연스럽다”라고 승인해 로컬 시제품의 기본 보행으로 채택했다. 이 선택은 영상의 보행에 대한 승인이다. 실제 다인 동시 조작·peer·최종 캐릭터/물리/Camera Gate 완료로 승격하지 않는다. Source 모델/rig/weight나 승인 animation clip 파일을 수정하지 않는다.
