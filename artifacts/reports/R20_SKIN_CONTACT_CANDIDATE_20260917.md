## 구현 규칙

- 승인한 모델·리그·가중치·팔 길이는 그대로다. 손이나 상대를 순간이동시키거나 표시 메쉬를 따로 옮기지 않는다.
- 렌더 보간 뼈 대신 고정 물리 snapshot의 뼈 행렬로 피부 표면을 계산한다.4622개 분산 정점을 먼저 찾고 원래 삼각형의 인접 면을 탐색한다. 잡은 뒤에는 같은 삼각형의 좌표를 유지한다.
- 전완마다6개, 총12개의 작은 접촉 구를 피부 안쪽에 배치해 표면이 접하도록 한다. 별도 Rigidbody는 없으며 해당 피부 부위의 기존 동적 몸체에 연결된다. 각 접촉 구는 지정된 전완에만 충돌하고, 연결된 상대 몸체의 기존 PhysicsMaterial을 그대로 사용한다. 마찰·반발 값을 새 기본값으로 대체하지 않는다.
- 기존 넓은 대상 충돌체와 해당 전완의 충돌만 접촉 구로 대체한다. 다른 신체와 바닥의 기존 충돌은 유지한다. mode 해제/장면 종료 때 원래 충돌쌍·질량중심·관성 및 자동 계산 설정을 복원한다.
- 기존 joint의 접점을 피부가 굽는 만큼 갱신하고, 실제 충돌·손끝 도달 검사를 통과한 경우에만 잡는다. 멀리서 붙이는 새 획득 규칙은 없다.
- 상대 총질량20kg·관성·중력 설정·활성 자세 drive0,80% 들기 보조와 마지막 손 release30N·s 던지기는 승인값을 유지한다. 피부 접점이 달라져 실제 기울기와 순간 높이가 달라질 수 있다. 한손 입력일 때만 팔 구동력을 기본의3배(상완45N·m/전완24N·m 상한)로 보완하고, 양손 입력은 기존2.5배를 유지한다. 양손 획득 중 첫 손만 먼저 닿았다고 한손 보완을 켜지 않는다.
