# R20 물리 펀치 떨림·사거리 밖 명중 표시 진단 — 2026-09-17

후속: 사용자 승인에 따라 [빠른 물리 펀치·명중 반동 후보](R20_FAST_PHYSICAL_PUNCH_20260917.md)를 구현했다. 아래의 ‘수정 미적용’은 원인 진단 당시 상태이며, 현재 후보·검증·남은 제한은 후속 보고서를 따른다.

상태: **떨림 재현·주원인 확인 / 오른쪽 아래 실제 명중 0 확인 / 동작 수정 미적용**. 사용자가 물리 펀치 후보의 떨림과 영상의 비접촉 명중 표시를 지적했다. 이전 후보의 기능 검증 통과는 동작 안정성 또는 사용자 시각 승인을 뜻하지 않는다. 다음 Down·회복 연결 전에 펀치 수정 후보를 검토한다.

## 확인 결과

### 1. 펀치 떨림은 실제 물리 동작 문제

상대와 닿지 않는 0.70m 거리에서도 재현된다. 승인된 동작을 참고 목표로 변환한 결과, 전완 관절 좌표에서 요구되는 최대 swing은 **76.57°**인데 전완 Y/Z 물리 제한은 각각 **4°**다. 목표 자세를 강하게 따라가는 drive와 회전 제한이 충돌한다. 기존 펀치 spring 8배·damper 1.5배는 이 충돌을 크게 드러낸다.

각 실험은 같은 모델·고정 60Hz·90 tick 안정화 뒤 왼손 짧은 클릭 1회로 진행했다. 한 조건씩 바꿨으며, 변경한 제한·충돌 설정은 해당 테스트 장면 안에서만 사용하고 장면을 폐기했다. 게임 코드의 관절 제한이나 충돌을 제거하지 않았다.

| 진단 조건 | 손끝 가속도 RMS (m/s²) | 전완 목표 추종 오차 평균 |
| --- | ---: | ---: |
| 기존 설정 | 375.85 | 53.18° |
| 자기 몸 충돌만 제거 | 376.13 | 53.20° |
| 어깨 제한만 제거 | 369.78 | 52.55° |
| 팔꿈치/전완 제한만 제거 | 47.73 | 2.44° |

수치는 떨림이 뚜렷한 진단 frame 26~34의 같은 구간이다. 손끝 위치의 고정 tick 중앙 차분으로 가속도를 계산했다. 정상 동작 가속도도 포함하므로 이 수치를 전체 품질 점수나 순수 떨림의 비율로 해석하지 않는다. 그럼에도 자기 충돌·어깨 제한 제거와 전완 제한 제거의 차이가 명확해 **현재 전완 목표와 제한의 불일치가 주원인**임을 확인했다. 감쇠만 늘린 실험은 일부 완화되지만 목표 추종 오차를 남겼다.

펀치 종료 시 어깨 제한이 즉시 복귀하는 코드도 있으나, 이번 주된 떨림은 펀치가 진행 중인 구간에 발생했다. 종료 전환을 주원인으로 단정하지 않는다. 원본 clip 자체의 결함 또는 모델 skin 결함이라는 결론도 아니다.

### 2. 영상 오른쪽 아래는 비접촉 명중을 누적하지 않음

대상은 이전에 전달한 `PhysicalPunch_HitCases_60.mp4`의 오른쪽 아래 `Far` 장면이다. MP4 전체 180프레임을 직접 디코드하고 frame 21·78·143·179의 실제 자막을 확인했다. 기록 데이터도 전체 180프레임과 대조했다.

- 펀치 **시도**: 1 → 2 → 3회.
- 실제 명중: 모든 프레임 **0회**.
- 누적 점수: 모든 프레임 **0점**.
- 실제 Hit 이벤트 목록: 비어 있음.

자막의 `펀치`는 시도 횟수인데 명중 숫자와 같은 크기·색으로 붙여 놓아 구분이 어려웠다. 원본 동작을 바꾸지 않고 오른쪽 아래 장면만 별도로 구성해 **명중·점수는 크게, 시도 횟수는 별도로** 표시했다.

- [구분을 명확히 한 기존 영상](../../.codex_tmp/punch-stability-20260917/Far_Original_ClearCounters_60.mp4)
- [실제 MP4 자막 추출](../../.codex_tmp/punch-stability-20260917/Decoded_Far_Counters.png)

이는 해당 영상의 비접촉 누적 의혹을 확인한 결과이며 모든 거리·자세에서 오판정이 없다는 보장은 아니다. 판정 범위 확대나 점수 규칙 변경은 하지 않았다.

## 수정 방향과 재검토 조건

물리 팔꿈치의 축·허용 범위를 기준으로 펀치 참고 자세를 다시 구성하고, 어깨 회전과 팔꿈치 굽힘을 분담한다. 무제한 관절, 충돌 무시, 손 강제 이동으로 해결하지 않는다. 그 뒤 구동력·감쇠와 종료 복귀를 조정한다. 기존 빠른 준비·좌우 대칭·실제 접촉 판정은 유지하는 수정 후보를 만든 뒤 사용자 시각 검토를 받는다. 이 문서 시점에는 해당 수정이 구현되지 않았다.

수정 후보 확인 항목:

- 좌우 허공 펀치에서 목표의 관절 한도 초과와 반복 반동을 측정한다.
- 실제 몸통/머리 접촉, 벽, 사거리 밖, 잡은 상태의 빈손 펀치를 비교한다.
- 시도·명중·부위 점수를 구분하고 1공격 1명중을 검사한다.
- 15/60/144FPS에서 같은 입력의 고정 물리 결과를 비교한다.
- 기존 잡기·들기·해제 던지기와 취소/초기화가 유지되는지 확인한다.
