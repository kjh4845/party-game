# R20 물리 팔 펀치·정밀 접촉 후보 — 2026-09-17

현재 후속 후보: [빠른 물리 펀치·명중 반동](R20_FAST_PHYSICAL_PUNCH_20260917.md). 아래는 이전 0.5초 clip 추종 후보의 기록이며 현재 동작 수치와 구분한다.

후속 사용자 피드백: **펀치 떨림 재현·전완 목표/회전 제한 불일치 확인, 수정 미적용**. 오른쪽 아래 사거리 밖 장면은 실제 명중 0·누적 0이며 시도 횟수만 증가했다. [진단과 수정 방향](R20_PHYSICAL_PUNCH_DIAGNOSIS_20260917.md)을 우선 참고한다. 아래 검증 결과는 이전 후보의 기능·접촉 검사 기록이며 동작 안정성 또는 시각 승인 완료를 뜻하지 않는다.

상태: **서 있는 상대·상호 잡기 승인 기록 반영 / 물리 펀치·점수 누적 후보 구현·검증 / 시각 검토 대기**. 사용자가 [잡기 접촉 후보](R20_STANDING_SKIN_CONTACT_20260917.md)를 승인한 뒤 펀치/정밀 타격 단계로 진행했다. 실제 Down·회복 전환과 전체3단계 완료를 뜻하지 않는다.

## 동작

- 150ms 미만 짧은 클릭 release는 해당 손 펀치,150ms 유지 후 실제 접촉은 잡기다. 마지막 본인 손 release는 기존 즉시 Throw이고 펀치를 추가하지 않는다. 다른 빈손은 독립적으로 펀치할 수 있다.
- 승인된0.7초/85프레임 참고 동작을1.4배로 사용해 요청 동작0.5초, 준비 약0.071초를 유지한다. 표시 뼈를 clip으로 덮어쓰지 않고 숨겨진 참고 자세를 관절 힘으로 따라간다. 실제 팔은 충돌·하중 때문에 참고 동작과 달라질 수 있다.
- 펀치 중 어깨 Y/Z 한도를85°/35°로 열어 준비 자세의 회전을 허용한다. 위팔/전완 spring은8배, damper1.5배, 최대 토크3배(45/24N·m)이며 물리 이동/팔 길이를 강제로 맞추지 않는다. 종료·취소 시 잡기 프로필15°/15°와 기존 구동력으로 복귀한다. controller disable 때도 다음 tick을 기다리지 않고 취소한다.
- source0.10~0.233초(실시간 약0.071~0.167초)의 실제 충돌만 명중 후보로 받는다. 실제 물리 손끝3cm+접촉 여유2mm 이내, 상대 부위에 대한 전방 상대 속도0.15m/s 이상을 요구한다. 팔꿈치·팔 중간·준비/회수 구간·벽/사거리 밖은 점수를 만들지 않는다.
- 같은 물리 tick의 접촉은 손끝 거리와 고정된 부위 순서로 정리해 callback 순서에 따른 부위 선택을 막는다. 한 공격은 같은 상대에게 한 번만 기록한다. 머리 물리 부위에 실제 접촉할 때만2점, 몸통·팔다리는1점이다.
- 추가 충격은 기존20N·s 이내, 맞은 물리 부위의 추가 속도1m/s 한도로 제한한다. 단순 접촉·잡기·던진 뒤 일반 충돌은 펀치 점수를 만들지 않는다.
- 마우스와 N/M의 실제 event 보유 시간을 고정 입력에 전달한다. 한 tick에 들어온 down/up,150ms 근처의 tap/hold, 메뉴/Reset 뒤 재무장도 구분한다.

## 점수와 아직 연결하지 않은 상태

기존 `PunchDownAccumulation`의 몸통/팔다리1·머리2·10→9→8→7→6 profile을 재사용한다. **이번 장면은 첫10점까지 누적한 뒤 Down 요청을 한 번 기록하는 단계**다. 그 뒤 추가 점수는 막고 R로 초기화한다. 실제8몸체 standing→12몸체 limp 전환, 잡기 유지 인계, DownCount·대기 시간 증가·회복은 다음 단계이므로 캐릭터가 아직 쓰러지지 않는다. 기존 기본 Shared Arena의 넉다운 정책을 바꾸지 않았다.
