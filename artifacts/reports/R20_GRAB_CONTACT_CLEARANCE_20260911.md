# R20 잡기 접촉의 손·팔 겹침 보정 — 2026-09-11

상태: **사용자 거절·철회·직전 버전 복원**. 겹침을 없애는 과정에서 승인된 팔 높이·자세·동작을 과도하게 변경했다. 사용자 지적에 따라 이 수정안의 코드와 관련 검사를 되돌렸다. 현재 기준은 [직전 자동 들기/상호 차단 버전](R20_AUTOMATIC_LIFT_REVIEW_20260911.md)이며 관통 문제는 미해결이다.

이하 내용과 수치는 거절된 실험의 기록이다. 현재 적용 상태나 사용자 승인, 관통 문제 해결의 근거로 사용하지 않는다. 수치 검사 통과만으로 승인된 모션을 바꿔도 되는 것은 아니다.

## 변경 내용

- 접촉점에 실제 충돌 표면의 바깥 방향을 함께 저장한다. Ray가 닿지 않아 ClosestPoint를 사용할 때도 표면 방향을 별도로 계산한다.
- 손의 원본 스킨/가중치에서 지지점을 추출해 손 두께와 방향에 맞는 목표를 계산한다. 고정 간격으로 손을 띄우는 대신 현재 손 모양이 표면 밖에 놓이도록 맞춘다.
- 벽에서는 팔꿈치가 벽 밖에 있는 두 관절 IK 해를 선택하고, 어깨와 팔꿈치를 바깥으로 벌려 손만 남기고 전완이 벽 안으로 들어가는 자세를 피한다. 팔 길이와 모델/가중치 원본은 바꾸지 않는다.
- 상호 잡기는 먼저 준비된 팔과 뒤따르는 팔의 경로를 구분한다. 뒤따르는 접촉은14cm 높은 위치에서 실제 Collider 접촉을 다시 확인한다. 좌우 손 모두 같은 관계 규칙을 사용한다.
- 유효한 접촉을 아직 찾지 못한 손도 자신을 잡으러 오는 팔을 그대로 관통하며 뻗지 않도록 준비 자세를 조정한다. 이 준비 자세는 접촉 승인이나 잡기 성공을 만들지 않는다.
- 손을 놓을 때는 어깨 쪽을 먼저 뒤로 빼고 팔을 내리는 순서를 사용한다. 잡힌 쪽의 빈 팔도 들어오는 손과 반대 방향으로 물러나 접촉 공간을 확보한다. 공격 중이거나 다른 행동이 사용하는 팔은 덮어쓰지 않는다.
- 접촉 해제 직후0.28초의 팔 복귀 공간은 표현용으로만 유지한다. 상호 들기 차단은 실제 잡기 관계가 풀린 즉시 해제되며, 이 표현용 정보가 던지기나 들기를 지연시키지 않는다.
- 매달림의 몸통 보정 뒤와 렌더 보간 뒤에도 해제 중인 팔이 벽 안으로 다시 들어가지 않도록 바깥 방향으로 보정한다. 렌더 보정은 시간이나 권한 상태를 갱신하지 않는다.

실제 접촉 검사의 SeekRadius/가림 검사로 잡기를 승인한다. 이미 잡힌 손의 유지 가능성은 고정 시점의 리그 위치와 팔 길이로 확인한다. 겹침을 가리기 위해 원래 잡기 검색 범위를 넓히거나 모델을 숨기지 않는다.

## 검증 범위

1. 벽 잡기·매달림·손 해제·옥상 복귀의 고정 프레임과 그 사이 다섯 보간 위치에서 실제 스킨 정점을 검사한다. 손·팔·어깨 영향 영역과 머리를 벽/옥상 Collider와 비교한다.
2. 상호 잡기는 두 캐릭터의 양쪽 위팔·전완/손 충돌 범위를 비교한다. 접근·유지·한쪽 해제·남은 잡기/들기 전환을 포함한다.
3. 가까운 거리, 비스듬한 접근, 한손/양손과15/60/144FPS를 추가 확인한다.
4. 기존 상호 자동 들기 차단, 즉시 release Throw, 넉다운 전환, 높은 벽의4방향×3깊이 복귀와 기존 전투 회귀 검사를 확인한다.

벽 검사에서 발바닥의 기존 접지 보정과 팔의 벽 관통은 따로 집계한다. 시나리오의 최초 위치 설정은 연속적인 이동이 아니므로, 최초 고정 포즈부터 이후 보간 구간을 검사한다. 측정 수치와 최종 테스트 결과는 [상세 기록](R20_GRAB_CONTACT_CLEARANCE_20260911.json)에 보존한다.

검토 시나리오의 손·팔·머리 메쉬 벽 관통은0m였다. 전체 메쉬에서 따로 집계한 발바닥 접지 침범은 약3.71mm로, 기존 접지 절충의 범위다. 상호 잡기는0.40/0.44/0.47m 간격, 정면 및±10도 접근, 한손/양손을 포함한8조건에서 팔 충돌 범위의 겹침0m를 확인했다. 위팔 반지름45mm·전완/손35mm의 기존 판정 범위를 사용하며, 렌더 보간 다섯 위치도 확인한다. 이 검사는 모든 가능한 캐릭터 메쉬 쌍의 정밀 삼각형 교차를 증명하는 검사는 아니다.

PlayMode31/31에는 기존 들기/즉시 던지기·상호 차단·Down/GetUp·정밀 히트·프레임 독립성과 벽4방향×3깊이 복귀 검사가 포함된다. 렌더 일정15/60/144FPS에서 물리 결과 차이0을 확인했다.

EditMode140/140, 문서 기준 검사 PASS·workflow7/7도 통과했다. 원본9개 자산의 hash를 확인했으며, 변경 소스 snapshot과 영상 디코드 검증을 상세 기록에 남긴다.

[수정 전후 확대 영상](../../.codex_tmp/grab-clearance-20260911/Media/GrabClearance60.mp4)은 왼쪽이 이전, 오른쪽이 수정이며 상호 잡기→벽 잡기 순서다. 원속도60fps를 유지한다.

## 재현

기본 `Project Hotfix > Prototypes > Open Shared Arena 2/3/4 Players` 또는 `Open Ledge Recovery Review`를 연다. 서로 마주 보고 좌/우 클릭을 유지한 뒤 한쪽 손을 놓아 팔 경로를 확인한다. 벽에서는 클릭 유지로 잡고 Space로 복귀하며 손과 팔이 표면 안으로 들어가지 않는지 확인한다.

최신 장면의 자동 들기, 상호 잡기 시 상승 차단과 마지막 손 해제 시 즉시 던지기는 유지한다. 정식 Prefab/Match/peer 통합이나 모든 미래 모델·움직이는 표면에 대한 충돌 검증 완료를 뜻하지 않는다.
