# R20 정적 가장자리 잡기·복귀 — 2026-09-10

상태: **로컬 시제품 연결·검증 완료**. 사용자가8.8×6.2CU 경기장과 최대22CU 카메라를 채택하고 가장자리 복귀 진행을 승인했다. 기본 `Open Shared Arena 2/3/4 Players` 메뉴는 이 경기장과 정적 Lip/Facade 복귀를 함께 연다.

## 동작과 입력

1. 벽 쪽을 향해 손이 닿는 곳에서 좌/우 클릭을 유지한다.150ms hold와 기존120ms reach 구간 뒤 실제 Collider 접촉이 있어야 잡힌다.
2. 한 손 이상으로 잡은 상태에서 Space를 누르면 상승 보조를 사용한다. 양손이어도 한 번의 요청은 한 번만 적용한다.
3. 몸이 올라가 팔의 도달 범위를 벗어나면 손을 놓는다. 더 아래에서 올라올 때는 버튼을 놓았다 다시 유지해 새 접촉을 만들고 Space를 다시 누른다.
4. 옥상에 실제로 착지하면 정상 이동으로 복귀한다. 공중당 보조는 최대2회, 요청 간격은350ms다. 손을 바꿔 잡거나 메뉴를 열어도 공중 사용 횟수는 초기화되지 않는다.

유효한 지지에100ms 머물고 표면을 잡고 있지 않으면 새 공중 구간의 보조 횟수가 준비된다. R은 검토 상태를 초기화한다. 표면을 놓거나 메뉴·Down·OOB·Reset으로 해제해도 맵에 Throw를 가하지 않는다. 캐릭터를 놓아 던지는 기존 경로는 유지한다.

## 물리·표현 경계

- Roof Lip과4개 Facade에 명시적으로 붙인 `ReviewGrabSurface`만 사용한다. 정적 Collider만 지원하며 손 경로가 막히거나 도달 불가능하면 잡지 않는다. 표시 bone을 판정에 읽지 않고 고정 시점의 팔 길이/위치와 물리 query를 사용한다.
- 매달림은 한 손당 최대2000N의 몸통 지지력과12,000N/m·600N·s/m의 spring/damping START로 계산한다. 실제 적용한 힘으로 기존 GripStress를 누적한다. 순간 위치 보정은 없다.
- 초기 joint-drive 검토에서는 읽은 force가0인 구간이 있어 피로 판정 근거로 사용할 수 없었다. 최종 구현은 제한해 실제 적용한 지지력을 사용한다.
- Space 보조는 옥상 위0.15CU를 목표로 필요한 상승량만 사용하며, 한 번의 상승량 상한은1.25CU다. 이 두 수치는 로컬 START이고 최종 체감 조정 대상이다. 기존 일반 Jump 높이/버퍼/코요테와 분리하며 일반 Jump modifier를 사용하지 않는다.
- 상승 중 수직 매달림 보조를 풀고, 새 접촉은 이전 상승 해제 구간을 상속하지 않는다. physics 직후에도 손의 도달 범위를 확인해 렌더 전에 유효하지 않은 잡기를 정리한다.
- 공중에서 벽을 향한 이동 구동력과 마찰만으로 몸이 벽에 정지하는 문제가 확인됐다. 이 시제품에서는 공중 capsule 마찰을0으로 하고 접지 시 원래 재질을 복구한다. 지상 마찰, 질량, 중력과 승인한 걷기1.40/달리기2.10m/s 설정은 유지한다.
- 상승 보조가 일반 공중 점프를 새로 허용하지 않도록 takeoff 상태를 표시한다. 잡기 전에 떨어지던 충격값도 새 착지 압축에 재사용하지 않는다.
- 전용 authored Climb clip은 추가하지 않았다. 기존 Grab IK와 공중/착지 하체 표현이 물리 결과를 따른다. 모델·리그·weight·승인 clip9개 원본 hash가 동일하다.

기본 `Project Hotfix > Prototypes > Open Shared Arena 2/3/4 Players` 또는 독립 `Open Ledge Recovery Review`를 연다. 기존 F키 조작 대상 전환·WASD·Shift·Space·마우스·Esc·R·F8은 유지한다.
