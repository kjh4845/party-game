# R20 빠른 물리 펀치·명중 반동 수정 후보 — 2026-09-17

후속 사용자 피드백: 때리는 대신 ‘툭 건드리는’ 느낌으로 **체감 미승인**. [준비·가격·힘 전달 동작 재수정](R20_PUNCH_FOLLOW_THROUGH_20260917.md)을 후속 후보로 검토한다. 아래 결과는 이전 후보의 기록이다.

상태: **구현·로컬 검증 완료 / 사용자 체감 검토 대기**. 사용자가 짧은 직선 펀치·떨림 해결·명중 반동 후보의 진행을 승인했다. 이번 결과는 다음 Down·회복 단계의 승인 또는 전체 전투 완성을 뜻하지 않는다.

## 검토 영상

- [좌우 연타 → 이동하며 치기 → 잡고 빈손 펀치·놓아 던지기](../../.codex_tmp/punch-snap-20260917/Media/PunchSnap_Flow_60.mp4): 7초·60FPS, 실제 명중 이벤트에 맞춘 타격음 포함.
- [같은 허공 펀치의 이전 / 수정 비교](../../.codex_tmp/punch-snap-20260917/Media/PunchSnap_BeforeAfter_60.mp4): 3초·60FPS, 왼쪽 이전 0.5초 / 오른쪽 수정 0.4초. 양쪽 명중 0.
- [좌우·머리·사거리 밖 접촉 기록](../../.codex_tmp/punch-snap-20260917/Media/PunchSnap_ContactCases_60.mp4): 3초·60FPS. 시도와 명중·점수 표시를 분리했다.

모두 Unity에서 실제 물리 동작을 촬영했다. 첫 영상은 좌우 연타/이동 장면의 앞 2초씩과 잡기/던지기 장면 3초를 연결했다. 접촉음은 게임에서 사용하는 PCM을 실제 Hit 이벤트 시각에 합성했다. 새 기본 펀치를 잡은 상태에도 사용하며, 별도 근접 훅은 이번에 추가하지 않았다.

## 바뀐 동작

- 한 손의 공격 상태는 0.5초에서 **0.4초**로 줄였다. 손을 0.06초에 걸쳐 접고, 0.14초까지 빠르게 뻗은 뒤 회수한다. 좌우는 같은 시간·힘·거울 방향을 사용하며, 기존의 독립 입력으로 번갈아 칠 수 있다. 이동을 공격 때문에 잠그지 않는다.
- 참고 자세를 실제 관절 좌표에서 구성한다. 팔꿈치 굽힘 목표는 X축만 사용하고 Y/Z swing 목표는 0이다. 전완의 기존 Y/Z 4° 제한과 모든 관절 연결·충돌을 유지한다. 이전에 요구하던 약 77°의 옆방향 회전 목표를 제거했다.
- 어깨가 팔의 방향을 잡는다. 최대 들어올림 목표 88°, 안쪽 방향 목표 좌우 ±30°다. 펀치 중 어깨 Y/Z 한도는 35°/15°이고 종료·취소 시 기존 15°/15°로 돌아간다. 원본 모델·skin weight·클립을 수정하지 않았다.
- 위팔/전완 spring은 기본의 6배/4배, damper는 2배, 최대 토크는 기존 펀치처럼 3배(45/24N·m)다. 실제 Rigidbody를 이동시키거나 표시 뼈를 펀치 클립에 고정하지 않고 관절 힘으로 따른다.
- 실제 명중 때만 회수 참고 동작을 앞당기고, 치는 손에 최대 0.3m/s 상당의 작은 반발 impulse를 준다. 맞은 부위의 자세 구동력은 잠깐 30%로 낮춘 뒤 0.12초에 걸쳐 복귀한다. 잡기 연결, 피해 점수, 물리 질량을 변경하거나 전역 시간을 멈추지 않는다.
- 실제 명중 때만 짧은 타격음을 재생한다. 몸통/머리 PCM은 같은 길이의 별도 음색이며 검토용 합성음이다. 소리·반동은 별도의 점수를 만들지 않는다.

## 판정과 기존 규칙

새 물리 동작에 맞춘 타격 구간은 공격 시작 후 **0.08~0.20초**다. 기존 `GroundHandActionStateMachine`에 선택적인 구간 설정을 추가했고, 다른 호출자의 기존 기본 구간은 유지했다. 이 시제품은 state 시간단위 0.7초 / 배속 1.75로 0.4초 상태를 만들며, 예전 승인 클립을 1.75배로 재생하는 구현은 아니다.

접촉 시점의 실제 손끝 반경 3cm + 기존 접촉 여유 2mm, 전방 상대 속도 0.15m/s, 1공격 1상대 1명중을 유지한다. 충돌 solver가 손을 이미 멈추거나 반발시킨 뒤 callback을 주는 경우를 위해, 고정 tick 직전 실제 손끝·상대 접점의 속도와 tick 동안 상대 이동을 함께 사용한다. 판정 근거를 `incomingClosingSpeed`와 `sweptClosingSpeed`로 기록한다. 참고 자세나 사거리만으로 명중을 생성하지 않는다.

몸통·팔다리 1점 / 머리 2점, 시간에 따른 누적 감소 없음, Down 기준 10→9→8→7→6 정책은 유지한다. **현재 검토 장면은 첫 10점의 Down 요청까지**다. 실제 쓰러짐·DownCount 증가·회복 인계는 아직 연결하지 않았다. 3초 전체 연타 촬영에서는 11회 시도 중 첫 10개 명중을 기록한 뒤 추가 점수를 막는다. 최종 체감 영상은 그 임계값 이전의 앞 2초를 보여준다.

짧은 클릭/150ms 유지 잡기/마지막 손 release 즉시 던지기의 구분과 다른 손의 잡기 유지도 보존했다. 반동이 끝날 때까지 새로운 조작을 강제로 막는 별도 경직은 추가하지 않았다.

## 검증 결과

- PlayMode **16/16**, EditMode **146/146** 통과. 새 구간의 경계·회수 중 판정 금지·중복 금지, 좌우/반대 플레이어 실제 타격, 잡기/던지기 구분, 취소/초기화, 기존 잡기 소유권·무구동 중력, native 루프를 포함한다.
- 15/60/144FPS에서 동일 고정 입력의 물리 위치 차이 0, 공격·명중·점수·잡기·던지기 상태 일치. 키보드 event의 147ms tap/153ms hold/짧은 tap은 기존 1.4와 새 1.75 시간 배율에서 통과했다.
- 좌우 허공 펀치의 팔꿈치 최대 swing 목표는 0°. 손끝 가속도 최댓값은 좌 200.55 / 우 200.04m/s², 마지막 안정화 구간의 한 tick 이동은 0.24/0.25mm였다. 이전 진단에서 반복적으로 제한에 부딪히던 원인을 제거한 결과이며, 가속도 수치를 재미의 평가값으로 쓰지 않는다.
- 8장면 × 180프레임 촬영: 좌우 각각 3명중, 머리 3명중/6점, 사거리 밖·벽은 0명중/0점, 잡고 빈손 펀치는 1명중·1던지기. 연타/이동 장면은 각각 11시도·10명중에서 첫 Down 요청 제한에 도달했다. 모든 프레임에서 명중 이벤트 수와 타격음 요청 수가 일치했다.
- 두 캐릭터 피부 표면 각도 최댓값 25.09°(기존 검사 기준 60° 미만).
- 준비/실제 명중/회수의 피부 표본 90개, 실제 명중 손 3개 검사: 최대 명중 손·피부 간격 **9.40mm**, 최대 표본 관통 **2.15mm**. 왼손 몸통 타격에서 미세 교차가 남아 있으므로 모든 접촉의 무관통 완료로 판정하지 않는다. 이번 변경은 펀치 동작 후보이며 해당 접촉 수치는 후속 보완 항목이다.
- 최종 MP4 420/180/180프레임 디코드 성공, 타격음 15개를 실제 명중 기록과 맞췄다. 문서 검사와 증거 해시/소스 snapshot은 [상세 기록](R20_FAST_PHYSICAL_PUNCH_20260917.json)에 보관한다.

## 실행과 다음 승인

`Project Hotfix/Prototypes/Open Physical Punch Candidate`에서 Play한다. WASD/방향키 이동, 마우스 좌우/N·M 짧은 클릭 펀치·유지 잡기, 마지막 손 release 던지기, R 초기화, Esc 입력 억제다. 이번 후보는 해당 검토 메뉴에 적용했으며 기본 Shared Arena를 교체하지 않았다.

사용자에게 준비·뻗기·회수의 속도, 연타 리듬, 실제 명중의 반동과 소리를 보여주고 체감 승인을 받는다. 그 전에는 별도 근접 훅이나 실제 Down·회복 인계를 추가 진행하지 않는다. 원본/검토 모델은 보존했다. Player Build·멀티플레이·4인 성능·전 장면 무관통 검증은 이번 완료 범위가 아니다.
