# R20 상체 능동형 래그돌 — 1단계 관절 검토

상태: **1단계 구현·실행 검증 완료 / 후속 진행 승인.** 1단계 결과 뒤 사용자의 진행 지시로 [2단계 잡기 검토](R20_ACTIVE_GRAB_STAGE2_20260915.md)에 착수했다. 아래 수치와 소스 snapshot은1단계 검토 당시 기록이다. 사용자는 권장안의 순서대로 구현하고 각 단계 결과를 승인받은 뒤 다음으로 진행하도록 지시했다. 기본 Shared Arena와 기존 전투/넉다운 구현은 바꾸지 않는다.

## 단계별 승인

| 단계 | 작업 | 현재 상태 | 다음 진행 조건 |
|---|---|---|---|
| 1 | 현재 모델의 상체 물리 관절 검토 | 구현·검증·후속 진행 승인 | 충족 |
| 2 | 두 캐릭터의 한손·양손·상호 잡기 | 기능 구현, 강한 하중 스킨 검사 실패 | 국소 형태 보완 범위 확인 후 재검토 |
| 3 | 실제 주먹 판정·펀치·즉시 던지기 연결 | 미착수 | 2단계 사용자 승인 |
| 4 | 벽 복귀·무력 넉다운·회복·2→4인 검토 | 미착수 | 3단계 사용자 승인 |

기존 손목/전완 접촉과 벽 접근·복귀 팔 전환 선택을 자동 확정하지 않는다. 해당 접촉/전환은 새 단계2·4에서 구체적인 결과와 함께 검토한다. 이전 국소 관통 보정안은 이력으로 보존한다.

## 실행과 확인

Unity 메뉴 `Project Hotfix > Prototypes > Open Active Upper Body Stage 1`을 연 뒤 Play한다. 이 장면은 Play 때 모델과 물리 검토 공간을 생성한다.

| 키 | 조작 |
|---|---|
| C | 기본 자세 → 앞으로 뻗기 → 팔꿈치 굽히기 |
| O | 왼팔 경로의 물리 장애물 표시/제거 |
| F | 왼손에 짧은 외력 적용 |
| G | 왼팔 근육 구동 켜기/끄기 |
| R | 위치·속도·구동·장애물 초기화 |

[실제 스킨 60FPS 영상](../../.codex_tmp/active-upper-stage1-20260915/Media/ActiveUpperBodyStage1_60.mp4)은 관절 운동 → 장애물 접촉/제거 → 외력 → 왼팔 힘 해제/복원 순서다.10.5초·630프레임을 디코드로 확인했다. 이 동작들은 관절 검토용 목표이며 최종 잡기·공격 모션이 아니다.

## 물리 구성

| 부위 | 몸체 수 | 질량 |
|---|---:|---:|
| 하체·골반을 대표하는 이동 몸체 | 1 | 8kg |
| Spine | 1 | 2.5kg |
| Chest | 1 | 2.5kg |
| Head | 1 | 3kg |
| 좌우 위팔 | 2 | 각각1.25kg |
| 좌우 전완·손 | 2 | 각각0.75kg |
| 합계 | 8 | 20kg |

7개 ConfigurableJoint의 구동력으로 보이지 않는 기준 골격의 목표 회전을 따라간다. 기준 골격에는 충돌체나 표시용 스킨이 없다. 실제 물리 몸체의 결과를 고정 시점에 스킨으로 복사하고, 렌더에서는 두 snapshot 사이만 보간한다. 물리 후 IK가 충돌 결과를 덮어쓰는 경로를 추가하지 않는다.

- 초기 관절좌표 기준 어깨 X −25~110도/YZ15도, 팔꿈치 X −5~135도/YZ4도다. 몸통과 머리는 제한된 범위에서 반응한다. 최종 전투용 관절 범위 확정은 아니다.
- 위치 joint는 연결을 유지하고 각도 구동은 spring/damper/maximum force를 가진다. projection 순간이동은 사용하지 않는다.
- 직접 연결된 인접 부위끼리만 충돌을 제외한다. 전완↔몸통, 좌우 팔, 환경과의 충돌은 활성화한다.
- 기존 넉다운용256/128 반복 설정을 그대로 사용하지 않고, 이 검토는 모든 몸체24/8 반복으로 수행한다.4인 성능을 검증했다는 뜻은 아니다.
- G로 왼팔을 풀면 해당 위팔/전완의 구동 spring·damper·maximum force가 모두0이다. 관절 연결, 회전 한도, 일반 물리 감쇠는 남는다. 전체 넉다운/회복 기능은 아직 연결하지 않았다.
- 기존 r20 모델·리깅·r07 가중치 및 기준 자산9개의 hash가 같다. 피부를 새로 만들거나 뼈를 추가하지 않았다.

## 검증 결과

- PlayMode11/11: 새 관절 검토8건과 기존 상호 들기 차단/기본 FixedLoop/등반 종료 정리 회귀3건.
- 강화한 실제 스킨 접촉 촬영 검사1/1. 위 촬영 검사와 중복되는 추가 실행이다.
- EditMode140/140.
- 15/60/144FPS에서630회 고정 연산의 물리 몸체 위치 차이0. 렌더한 뼈가 다음 물리 입력으로 되돌아가지 않음을 검사했다.
- 장애물 접촉115회 관측. 최대 충돌체 침범 약0.98mm, 관절 접점 오차 약3.81mm. 막혀 있을 때 손 목표 오차 약206mm가 생기고 장애물 제거 후 약54mm로 복귀했다. 힘으로 따라가는 목표이므로 자유공간에서도 중력에 따른 자세 오차가 남는다.
- 실제 스킨 정점의 해당 장애물 침범0m. 접촉 구간에서 보간0/0.5/1을 검사했다.
- 활성화한 비인접 자기 충돌체 쌍의 침범0m(기본/뻗기/굽히기 시나리오).
- 왼팔 구동 해제 시 손이 약245mm 내려갔고, 오른팔은 목표 유지 상태였다. 왼팔 구동 복원도 확인했다.
- 영상 전 구간의 최대 인접 삼각형 표면 각도 약31.6도. 측정 기준60도 미만이며, 모든 메쉬 자체 교차를 증명하는 검사는 아니다.

검증은 이 단일 캐릭터·정적 장애물 장면에 한정된다. 서로 잡는 캐릭터, 고속 타격, 이동/점프, 실제 다인 조작과 peer 성능은 다음 단계다. 성공한 기술 검사를 사용자 시각/체감 승인으로 대체하지 않는다.
