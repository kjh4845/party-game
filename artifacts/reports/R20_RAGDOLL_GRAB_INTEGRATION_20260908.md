# 분할 래그돌의 잡기·점프·던지기·회복 연결

사용자 결정: **잡힌 상태에서도 실제 지지와 기립 공간이 있으면 회복하며, 잡기는 유지한다.** 기존 고정5회 피격, 시간 감소 없음, DownCount별 대기 시간 증가, 일반 충돌 피해 제외 규칙을 유지한다.

## 변경

- 캐릭터의 전체 동적 body를 하나의 잡기 대상으로 계산한다. 분할 래그돌의 골반3kg만 보던 하중을 실제 전체20kg으로 바로잡았다.
- 몸통/팔다리 proxy도 원래 캐릭터로 식별하고 실제 닿은 Rigidbody에 joint를 연결한다. 접점은 해당 body의 좌표로 저장한다.
- 서 있는 충돌체→분할 래그돌→서 있는 충돌체 전환은 topology version으로 구분한다. 전환과 손 해제 입력이 같은 tick에 겹쳐도 release 판정 전에 접점을 갱신해 Throw를 누락하지 않는다. 새 표현에서 기존 world 접점을 이어 붙인다. 일반 collider 비활성/삭제나 Reset을 정상 전환으로 오인하지 않는다.
- 잡기 하중과 점프75% 부분 보정은 전체 질량과 질량 평균 속도를 사용한다. 같은 캐릭터를 양손으로 잡아도 한 번만 계산하며, 모든 부위에 동일한 추가 상승 속도를 준다.
- release Throw는 전체 질량으로 상한을 계산하고 부위 질량에 비례해 impulse를 분배한다. 총 impulse를 body 수만큼 중복하지 않는다. 동일 대상의 마지막 본인 손 release만 Throw이며 강제 해제/Reset은 Throw0이다.

## 잡힌 상태의 회복

다른 플레이어가 잡고 있다는 이유로 timer를 늘리거나 자동으로 손을 놓지 않는다. 실제 힘/거리/피로/대상 상실에 의한 기존 break 조건은 유지한다.

이미 대부분 서 있는 자세로 잡혀 있으면 timer 만료, 실제 발 지지, clearance 이후 짧은 물리 자세 안정화(`UprightReturn`)로 복귀한다. 몸과 부위가 기본 기립 위치에 안정되기 전에는 입력을 풀지 않는다. 머리가 아래로 향하거나 지지/공간이 없으면 이 경로에 들어가지 않는다.

누운 상태는 기존 방향별 회복 단계를 따른다. 외부 잡기가 유지되는 동안에는 접점과 몸이 분리돼 보이지 않도록 물리 bone pose를 우선한다. 잡기가 풀리면 진행 중이던 GetUp의 현재 시각으로0.18초 시각 보간하며, gameplay timer나 clip 시간을 되돌리지 않는다. 넉다운 대기 구간의 animation/pose drive0은 유지한다.

몸 중앙 아래의 검사만으로 양발 지지를 놓치지 않도록, 잡힌 대상은 실제 collider 바닥 가까이에서 접촉을 검사하고 같은 지지면 위의 기립 위치를 확인한다. 잡은 지점의 원래 기립 기준을 사용해 몸이 기울었다는 이유로 기립 목표가 어긋나지 않도록 한다. 자기 collider는 제외하고, 발이 닿지 않는 좁은 중앙 발판은 지지로 인정하지 않는다. 잡기가 풀린 분할 래그돌도 실제 바닥 접촉을 먼저 확인한 뒤 골반 기준 기립 위치를 같은 지지면에 투영한다. 누운 가슴 아래 위치를 기립 위치로 오인해, 이미 공간이 있는데도 주변 캐릭터 때문에 회복이 계속 막히는 문제를 수정했다.

## 검증 항목

- 12 body·20kg과 mass-average velocity, 전체 impulse 보존, Reset 후 단일 body20kg.
- 실제 hold로 잡고 Down 전환 시 몸통 부위로 재연결, release Throw30N·s START와 추가 피해/Down0.
- 양손 유지 상태의 회복과 마지막 손 해제만 Throw1. Down 전환 바로 다음의 release 입력도 Throw1.
- 양손 점프 보정의 대상 중복0, 전체 부위 속도 변화와 총 추가 impulse.
- timer가 끝나도 천장에 막히면 대기, 제거 후 잡기를 유지한 회복.
- 좁은 발판의 가짜 지지 거부, pose 재진입 시 root 불변과 clip 재시작0.
- 실제 한 손 hold + 반대 손 유효 Punch5회 → Down → 기립 공간이 막힌 동안 잡기 유지/대기 → release Throw → 착지/회복. 공간이 있는 잡힌 채 회복은 별도 양손 fixture로 확인한다.

원본 모델·rig·weight와 GetUp clip asset은 수정하지 않는다. 이 결과는 로컬 시제품이며 peer·실제 다인 수동 조작·최종 balance/성능 승인을 대신하지 않는다. 바닥에 완전히 낮게 누운 대상의 접촉 가능 범위는 실제 팔 reach를 따르며 별도 무제한 팔 늘림이나 crouch 입력은 추가하지 않는다.

## 실행

Unity `Project Hotfix > Prototypes > Open Articulated Punch Candidate`에서 Play한다. 한 손 버튼을 유지해 잡고, 반대 손을 짧게 눌러 펀치한다. 대상이 회복할 공간을 확보한 상태에서 잡기 유지와 release Throw를 확인한다. R은 초기화, Esc는 기존 입력 취소/재무장이다.

결과와 영상·소스 snapshot은 [구조화 검증 기록](R20_RAGDOLL_GRAB_INTEGRATION_20260908.json)에 보존한다.
