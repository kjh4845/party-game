# 일어난 직후 흔들림 수정

사용자 요청대로 회복 동작 자체는 유지하고, 회복 완료 시 물리 상태를 이동 상태로 넘기는 부분만 수정했다.

## 변경

기존에는 같은 tick에서 회복 force/torque를 예약한 뒤 회복 완료를 판정하고 mass/inertia/constraint를 교체했다.
이제 완료 판정을 먼저 하고, 완료한 tick에서는 회복 force/torque를 더 예약하지 않는다.
설정 변경과 보조 body 정리가 모두 끝난 뒤 잔여 회전 속도를 정리한다. 선운동량과 이동 입력은 유지한다.
위치·방향을 목표 pose로 순간이동하거나 회복 clip을 다시 제작하지 않는다. 수정은 현재 animation 회복 경로에 적용하며, 과거 비교용 physics-only 경로는 당시 동작을 보존한다.

## 검증

`GetUpHandoffTests`: 앞/뒤/좌/우 회복 후1초 idle의 회전·높이 변화, 이어지는0.5초 이동을 실제 PhysicsScene으로 측정한다.
회전 변화1° 미만, 각속도0.2rad/s 미만, 높이 변화1mm 미만, 이동 거리0.2m 초과를 회귀 기준으로 검사한다.
수정 전/후 실제 측정값과 전체 검사 결과는 구조화 기록에 보존한다.

- 준비·회복 animation2개와 구간 timing은 변경하지 않았다. clip SHA-256과 완료 tick을 비교한다.
- 회복 이후 별도의 입력 잠금이나 이동 대기 시간을 추가하지 않았다.
- 래그돌의 무력 구간, 모델/리그, 잡기·점프 및 일반 충돌 피해 제외 규칙은 유지한다.

재현: Unity PlayMode 필터 `GetUpHandoffTests` 또는 전체 PlayMode 검사.
기존 `Open Ragdoll Recovery Candidate`에서1/2/3/4로 넘어뜨린 뒤 일어난 직후를 확인할 수 있다.

## 최종 결과

- 최종 소스 기준 PlayMode 37/37, EditMode 110/110 통과.
- 앞/뒤/좌/우 모두 회복 완료 tick은 수정 전과 동일했다.
- 회복 직후 1초간 높이 변화: 기존 약 6.4mm → 최대 0.188mm.
- 같은 구간 회전 변화는 최대 0.671°, 이후 0.5초 이동은 네 방향 모두 0.271m 이상이었다.
- 두 회복 clip과 보존 대상 Blender 원본/후보 네 파일의 SHA-256 일치를 확인했다.
- 상세 측정값·최종 소스 snapshot·검사 XML·비교 영상 출처: [구조화 검증 기록](R20_GETUP_HANDOFF_FIX_20260907.json).

검증 범위는 로컬 Unity 프로토타입이다. 최종 게임 통합 및 플레이 감각 승인을 의미하지 않는다.
