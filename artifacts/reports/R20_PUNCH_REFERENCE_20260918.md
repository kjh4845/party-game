# R20 단단한 펀치 원형 검토 — 2026-09-18

상태: **재설계 1단계 원형 제작·검증 / 사용자 모양·리듬 승인 대기**. 사용자가 [재설계 순서](R20_PUNCH_CONTROL_REDESIGN_20260918.md)의 진행을 요청했다. 이번 결과는 물리 없는 참고 동작이며, 실제 게임의 펀치·명중·피격을 수정한 결과가 아니다. 원형 승인 뒤 2단계 자세·속도 기반 물리 추종을 검토한다.

- [0.5배 느린 확인](../../.codex_tmp/punch-reference-20260918/Media/PunchReference_HalfSpeed.mp4): 동일180프레임을30FPS로 재생한6초 영상. 원속도 판정을 대체하지 않는다.
- [준비·타격 자세·회수](../../.codex_tmp/punch-reference-20260918/Media/PunchReference_KeyPoses.png).

자막에 물리 추종/명중 판정 미연결을 명시했다. 상대 캐릭터·가짜 피격·명중 카운터·타격음은 없다. 새 검토 장면의 Rigidbody와 Collider는 각각0개다. 동작 형태의 문제와 물리 추종의 문제를 분리하기 위한 장면이다.

## 원형의 구성

2026-09-05에 사용자가 좋아했던 팔꿈치 중심 방향을 참고했다. 당시 승인 범위는 준비 속도와 동작 모양이었으며 새 원형의 승인으로 확대하지 않는다. 기존 승인 클립을 덮어쓰거나 동일한 동작이라고 주장하지 않는다.

- 0~0.085초: 팔꿈치를 접어 주먹을 모으고 어깨를 준비한다. 굽힘 목표는 최대115°다.
- 0.085~0.105초: 골반·몸통·어깨가 먼저 움직이고 팔꿈치는 접힌 상태를 유지한다.
- 0.105~0.150초: 앞으로 뻗으며 가속한다. 어깨86°·팔꿈치8°를 기준으로 거의 편 자세를 만든다.
- 0.150~0.167초: 타격 자세를 짧게 보여준다. 실제 명중이나 hit-stop이 아니라 참고 동작의 구간이다.
- 0.167~0.250초: 짧은 반동 자세를 거쳐 주먹을 회수한다.
- 0.250~0.350초: 팔과 몸통을 원래 자세로 정리하고,0.4초까지 대기한다.0.4초는 시각 비교 기준이며 새 전투 타이밍의 확정이 아니다.

골반 회전 최대2°·Spine 추가 회전1.5°·Chest 회전4°·상체 기울기5°를 작은 범위에서 연결한다. 골반의4mm 이하 이동/낮춤은 참고 스킨의 자세 변화이고 게임 루트 이동이 아니다. 두 발의 위치·방향은 IK로 유지한다. 기존 메쉬·weight·뼈 개수·팔 길이는 바꾸지 않았다.

참고 자세의 몸통·팔을 직접 표시하는 코드는 전용 `PunchMotionReferenceReview`에만 있다. 기존 물리 펀치에 이 방식으로 표시 뼈를 덮어쓰지 않는다.

## 검사 결과

PlayMode **3/3** 통과:

1. 좌우49개씩120Hz 자세 표본: 대칭·발 접지·팔 길이·시작/끝 자세·불규칙한 평가 순서의 재현성, 피부 표면의 급격한 꺾임 검사.
2. 실제 Unity 정면/측면360장 촬영 및 영상 데이터 기록.
3. 공유 모델 로더를 쓰는 기존 캐릭터 생성 경로가20kg Rigidbody·CapsuleCollider·24개 skin bones를 그대로 유지하는지 검사.

- 좌우 뼈 위치 대칭 최대 오차 약4.66e-10m.
- 발 목표 오차 약9.00e-8m, 팔 길이 변화0, 시작/끝 회전 차이0, 같은 시간의 재평가 위치 차이0.
- 피부 표면 인접면 각도 최댓값21.03°(검사 기준60° 미만), 바닥 높이 차이는 수치 오차 수준이다.
- 이는 전체 자기교차나 실제 물리 충돌 품질의 증명이 아니다. 이번에는 실제 힘·피격·15/60/144FPS 전투 재생을 검사하지 않았다.
- 120Hz 표본에서 전완 세계 회전속도 최댓값은 약62.64rad/s다. 기존 물리 상한60rad/s 부근이므로 다음 단계에서 속도·토크 포화와 실제 추종을 별도로 확인해야 한다. 원형의 그대로 추종 가능성은 아직 승인하지 않는다.
- 원속도/느린 영상 각각180프레임 디코드 성공. 원본·검토 모델과 승인 펀치 소스는 해시로 보존을 확인했다.
