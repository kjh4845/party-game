# R20 래그돌 들기 보조·놓기 던지기 후보 — 2026-09-17

상태: **사용자 시각/체감 승인 완료(2026-09-17)**. 사용자가 “이정도면 된것같다 다음단계 진행하자”로 승인했다.80% 무게 보조와 들기·즉시 놓기 던지기를 후속 후보의 기준으로 삼는다. 다음 손/피부 접촉 보완을 진행하며, 전체2단계·3단계나 기본 Shared Arena 적용 완료를 의미하지 않는다.

## 동작

- 바닥에 쓰러져 있기만 하면 보조0. 실제 손 접촉으로 잡고, 보유자가 바닥 지지를 받으며 들어 올리거나 유지할 때만 위쪽 힘을 더한다.
- 대상12개 물리 몸체의 총질량20kg·각 관성·중력 설정을 유지한다. 관절의 활성 자세 drive0이며 애니메이션으로 상대를 세우지 않는다.
- 현재 검토값은 중력의80% 보상이다. 대상 전체에 최대156.96N을 한 번 적용한다.20% 무게는 남으며 한손/양손/여러 접점이 보조를 중복하지 않는다. 진입0.18초, 종료는 즉시다.
- 팔의 목표 높이를 잡은 높이에서 최대0.65m,0.85초에 걸쳐 올린다. 실제 팔 길이와 접촉 joint가 이동을 제한한다. 상대 Transform·속도를 목표점으로 덮어쓰지 않는다.
- 잡은 쪽 팔 구동력을 이 후보에서만2.5배로 올린다(상완 최대37.5N·m, 전완20N·m). 약한 기존 팔 구동력만으로는 무게 보조 후에도 실제 상승이 부족했다. 상대의 관절 복원력은 추가하지 않는다.
- 양손 중 하나 release는 나머지 손 유지. 마지막 유효 본인 손 release에서 보조를 끄고 기존30N·s/추가속도상한3m/s 규칙의 던지기를1회 적용한다.20kg에서는 추가1.5m/s이며 방향은 전방+상향0.35 비율이다. 들기 완료를 기다리지 않는다.
- 메뉴·Reset·보유자/대상/콜라이더/그립 상실에는 보조0·추가던지기0. 상호 잡기는 양쪽의 추가 자동 상승을 멈춘다. 보유자가 공중으로 전환하면 중력 보조를 중단한다.

수치는 최종 밸런스 확정이 아닌 START다. 기본 Shared Arena와 원본 승인 모델을 교체하지 않았다.

## 재현

1. Unity 메뉴 `Project Hotfix/Prototypes/Limp Lift Candidate/Face Up`을 열고 Play한다. Face Down/Left Side/Right Side도 제공한다.
2. WASD로 누운 상대에 접근하고 왼쪽/오른쪽 마우스를 유지한다. 실제 손 접촉 이후 자동으로 들어 올린다.
3. 한 손만 놓아 유지, 마지막 손을 놓아 던지기를 확인한다. R은 reset, Esc는 입력 억제/강제 해제다.
4. 이전 `Low Ragdoll Grab` 메뉴는 들기 없는 비교를 위해 보존한다. 새 장면에는 점프 입력·시간제 회복·피격 시스템이 아직 없다.

## 남은 경계

손과 실제 피부 사이 간격은 이번 작업으로 해결하지 않았다. 이전 잡기/끌기 검토에서 약3.6cm였다는 기록을 새 들기 구간의 상한으로 사용하지 않는다. 후속 진행 승인에 따라 피부를 따르는 국소 접촉면 후보를 검토한다. 이 보고서의 기존 영상·측정값은 들기 승인본의 이력으로 보존한다.

이 대상은 영구 Down 검토용이다. 실제 피격→Down→회복 전환, 기믹/OOB, 새 물리 팔의 타격 판정, 다인·네트워크와 게임 전체 적용은 후속이다. 새 들기 장면의 바닥 지지 판정은 평면 검토 바닥 기준이며 실제 지형 통합은 별도다.
