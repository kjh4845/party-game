# 월드 발 고정 도달 범위 검사 — 2026-09-06

사용자가 기본 보행 재작업에 이어 발 미끄러짐 보정을 별도로 진행하도록 요청했다.
현재 ReadableGait의 실제 물리 이동 경로와 승인 리그에서 발 고정 목표의 도달 가능성을 측정했다.
**검사 완료, 후속 절충 후보 제작 승인**이다. 사용자가 “그래도 돼”로 속도·발놀림을 함께 조정한 비교 후보 제작을 승인했다. 월드 발 고정 구현 완료나 최종 접지 PASS를 뜻하지 않는다.

걷기·달리기 각각8방향, 총16조건·7,680physics step을 검사했다. 위 반올림 값은 방향 간 동일했다.
지지 시간은 첫 지지 표본부터 마지막 지지 표본까지의 간격이며, 경계는60Hz 해상도다.
발 고정점은 지지 시작 첫 표본의 발 뼈 위치이고 이후 월드 좌표를 바꾸지 않았다.
실제 hip과 고정점 사이 거리를 허벅지+종아리 길이 약155.4mm와 비교했다.
도달 불가능한 목표로 mesh를 변형하거나 부족한 길이를 늘려 숨기지는 않았다.

## 원인과 결정이 필요한 부분

현재 지지 구간에 root는 약395~444mm 이동한다. 이전 기하 검사에서 골반을25mm 낮추더라도
가능한 앞뒤 전체 범위의 낙관적 상한은 약170mm였다. 현재 골반 동작의 실제 범위는 더 작다.
따라서 목표점만 고정하거나 IK 정확도를 높여서 현재 속도·주기·모델 비율을 모두 유지한 채
지지 구간 전체의 미끄러짐을 없앨 수 없다. 짧게 고정했다가 해제하는 방식도 나머지 구간의 이동을 없애지는 않는다.

사용자에게 **이동 속도를 낮추고 발놀림을 함께 빠르게 조정하는 절충 후보 제작**을 제안했다.
게임 속도를 반드시 유지해야 한다면 더 빠른 발놀림 또는 일부 미끄러짐 허용이 필요하다.
이동 속도와 보행 리듬은 조작감·외형에 영향을 주므로 후속 승인 범위에서 별도 후보로만 조정하며 기본 설정에 자동 채택하지 않는다.
기존 빠른 발/느린 이동 비교 후보를 자동 채택하거나 과거 영상에 대한 승인을 가정하지 않는다.
