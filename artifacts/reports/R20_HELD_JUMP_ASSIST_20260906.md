# 잡은 상태 점프 높이 보정 — 2026-09-06

> 후속 사용자 요청으로 현재 기본값은 [무게감을 남기는75% 부분 보정](R20_HELD_JUMP_WEIGHT_20260906.md)이다.
> 아래100% 보정과 solo 동일 높이는 이전 비교 이력으로 보존한다.

사용자가 잡은 상대와 싸울 때 더 높이 점프할 수 있도록 요청했다.
동일한20kg 상대를 잡은 경우 **혼자 점프하는 높이에 가깝게 올라가도록** 물리 시작 속도를 보완했다.
점프 높이 설정0.25m, 이동0.70/1.05m/s와 모델·리그는 유지한다. 재미·최종 밸런스 확정은 후속 통합 플레이테스트에서 판단한다.

| 조건 | 캐릭터 상승 높이 | 상대 상승 높이 |
|---|---:|---:|
| 혼자 | 약23.19cm | — |
| 상대를 잡고, 이전 방식 | 약5.35cm | 약5.35cm |
| 상대를 잡고, 보정 | 약23.19cm | 약23.19cm |
| 같은 상대를 양손으로 잡고 보정 | 약23.19cm | 약23.19cm |

| 100kg 대상, 보정 예산 상한 적용 | 약5.35cm | 약5.35cm |

높이는 평지에서 PhysicsRoot의 시작 위치 대비 최고 y 변화다.0.25m 설정과 실제23.19cm의 차이에는
60Hz 물리 적분이 포함된다. 표의 값은 해당 검토 몸체·접촉 조건이며 모든 지형과 하중의 보장이 아니다.

## 보정 방식과 제한

- 권한 jump가 실제 승인된 physics step에서만 보정한다. 공중 요청 자체가 추가 점프나 보정을 만들지 않는다.
- 손 입력·대상 유효성·joint 해제를 처리한 뒤 현재 잡고 있는 동적 대상만 선택한다.
- 같은 Rigidbody는 양손으로 잡아도 한 번만 선택한다. 이미 충분한 상승 속도를 가진 대상에는 더하지 않는다.
- 대상의 추가 상승 속도는 기본 점프 시작 속도까지만 보완하고, 대상 하나에 더하는 속도 변화도 그 시작 속도 이내로 제한한다.
- 추가 운동량 예산은 `본인 질량 × 시작 속도 × 최대 지원 질량 비율`이며 비율 상한은2다.
  같은 step의 대상들에 비례 배분한다.100kg처럼 상한을 넘는 하중은 여전히 낮게 뛴다.
- `HeldJumpAssistance=1`, `MaximumAssistedMassRatio=2`는 이번 시작값이다.0으로 설정하면 이전 방식과 비교할 수 있다.
- 점프 시작 y 속도를 권한 단계에서 즉시 확정한다. 서로의 점프와 잡기 보정이 같은 physics step에 들어와도
  미반영 AddForce가 두 번 쌓이지 않는다. 위치 순간이동이나 중력 변경은 없다.
- 수평 속도·기본 mass·joint break 기준·GripStress 정책은 바꾸지 않는다. Hit/Damage/Throw event를 합성하지 않는다.

무거운 대상을 무제한으로 들어 올리는 방식은 아니다. 추가 보정의 질량 예산과 속도 상한이 있다.
이미 받은 다른 외력까지 지우는 전역 속도 제한도 아니다. 이 보정이 추가하는 상승분을 제한한다.

## 검증

- 전용23조건: 혼자/이전/보정, 양손 중복, 대상 둘, 무거운 대상, 놓은 뒤 점프, 무효 대상,
  공중 재요청·재점프·Reset 후 재점프,8방향 이동 중 점프, 상대도 동시에 점프하는 두 처리 순서,
  서로 잡은 두 캐릭터의 동시 점프 두 처리 순서.
- 같은 상대 양손 잡기의 추가 운동량은 한손과 같았고, 동시 점프는 순서를 바꿔도 최고 높이가 같았다.
- 해제·무효 대상에는 보정0, 공중 반복 요청은 추가 점프0. 재점프와 Reset 뒤 새 점프는 각각 새 보정을 받았다.
- 8방향과 서로 잡은 동시 점프에서 joint break0. 손끝 접촉 오차와 도달 범위 보정은 기존 기준 이내였다.
- 기존 Grab 물리22조건·256표면 표본도 다시 통과했다. 더 높아진 잡기 점프 구간의 최대 인접 면 각도 약40.89°,
  45° 이상 꺾임0·90° 이상 뒤집힘0, 잡기 해제 없이 착지했다.
- 혼자 점프하는 기존 물리 검사와 점프/착지·팔 조합 회귀를 포함해 전체 EditMode96/96·PlayMode26/26 통과, skip0.

현재는 로컬 검토 몸체와 테스트 입력을 사용한다. 실제 peer 입력·최종 physics profile·맵 전투의 체감 검증은 후속이다.
들기·추가 던지기 impulse·피해/Down·회복·정적 Ledge/ClimbAssist의 완료를 뜻하지 않는다.
