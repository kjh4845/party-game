## 물리와 소유권

- 양쪽의 고정 물리 snapshot에서 피부 표면을 계산한다. 표시 프레임 보간이 다음 물리 입력으로 되돌아가지 않는다.
- 각 전완에6개, 두 캐릭터에 총24개의 접촉 구를 사용한다. 추가 Rigidbody는 없고 캐릭터당 기존8개 몸체·20kg·질량중심·관성을 유지한다. 접촉면은 붙은 몸체의 PhysicsMaterial을 사용한다.
- 서로의 전완끼리는 같은 물리 접촉을 두 번 만들지 않는다. 한쪽 전완과 상대의 피부 접촉면으로 처리하며 양쪽 Rigidbody가 실제 충돌/반작용을 받는다.
- 둥근 손끼리는 표면 두 점을 억지로 고정하지 않고 손 중심 간 거리 제약으로 굴러 움직일 수 있게 한다. 같은 접촉은 물리 연결1개를 공유하고 각 손의 소유권은 별도다. 양손 상호 잡기는 논리4개/물리2개다.
- 몸통 등 다른 부위를 잡으면 같은 피부 삼각형의 지점을 유지한다. 상대 Rigidbody에 힘을 전달하며 메쉬·루트·팔 길이를 표시용으로 옮겨 틈을 숨기지 않는다.
- 한쪽이 놓아도 상대 소유가 남으면 연결은 유지한다. 상호 잡기 동안 추가 자동 들기를 막으며, 유효 마지막 본인 손 release의30N·s/추가속도상한3m/s Throw는 유지한다.
- 손 충돌체가 사라지거나 trigger가 되는 경우에는 잡기를 취소하고 추가 Throw를 만들지 않는다. 취소·초기화·모드 종료 때 연결과 충돌쌍·관성 자동 계산 상태를 복원한다.

## 검증과 재현

PlayMode 19/19, EditMode 140/140 통과. 양쪽 플레이어의 좌/우/양손, 입력 처리 순서, 공유 소유권·부분 해제, 상호 들기 차단과 즉시 Throw, 입력 재무장·강제 취소, 기본 Unity 물리 루프와 기존 누운 상대/잡기 점프 회귀를 검사했다.15/60/144FPS의 같은 고정 입력 재생에서 물리 위치 차이0과 상태 일치를 확인했다. peer 간 결정론 보장은 아니다.

접촉면 갱신만의 로컬 Editor 중앙값3.43ms·95백분위3.59ms다. 캐시 생성·추가 aim/충돌 callback 조회·PhysX·렌더 비용을 포함하지 않으며4인 성능 인증으로 사용하지 않는다.

1. Unity 메뉴 `Project Hotfix/Prototypes/Standing Skin Contact/Lift and Release`에서 Play한다.
2. 1P는 WASD·마우스 좌우 유지,2P는 방향키·N/M 유지로 잡는다. R 초기화, Esc 입력 억제를 사용한다.
3. 한쪽 손 또는 한쪽 플레이어만 놓아 상대 잡기가 남는지 확인한다. 마지막 본인 손 release는 즉시 던지기를 만든다.
4. `Contact Comparison Only` 메뉴는 들기/던지기를 끈 접촉 검토용이다. 기존 메뉴·기본 Shared Arena는 자동 교체하지 않는다.
