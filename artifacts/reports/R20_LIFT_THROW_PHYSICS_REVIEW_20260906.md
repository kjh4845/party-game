# 들기·던지기 공통 물리 검토 — 이전 API 검증 기록

> 후속 사용자 결정: [클릭 유지 Grab→버튼 release Throw](R20_RELEASE_THROW_REVIEW_20260906.md). 아래 선택 대기는 이 검토 당시의 이력이며 현재 대기 상태가 아니다. 별도 들기 키 없이 진행한다.

다음 CHR-007 단계의 **입력 방식과 독립적인 물리 API와 pose를 구현·검증했다.**
기존 문서에는 들기·던지기 키와 조작 방법이 확정되어 있지 않아 사용자에게 선택을 요청했다.
현재 답변 대기이며, Ctrl 또는 양손 자동 들기를 임의로 기본 입력에 연결하지 않았다.
기존 잡기 장면에서 새 키로 실행할 수 있는 상태까지 완료했다는 뜻은 아니다.

## 공통 구현

- `SetLiftRequested(true/false)`에 따라 실제 joint anchor를 천천히 이동해 들거나 내린다.
  목표는 위로0.10m·몸 쪽으로0.06m, 전환 시간0.50초 START다. 대상의 transform을 직접 이동하지 않는다.
- 같은 대상의 양손은 하나의 들기 진행도를 공유한다. 이미 든 대상에 두 번째 손을 붙여도 높이가 다시 더해지지 않는다.
- 대상 collider bounds의 sweep으로 천장·장애물 방향의 추가 들기를 막는다. 중력·충돌·GripStress는 계속 계산한다.
- `TryThrow(side)`는 유효하게 들고 있는 대상을 명시적으로 던진다. 해당 대상에 붙인 **본인 손**의 joint를 모두 해제한 뒤 힘을1회만 적용한다.
- 기본 impulse30N·s, 대상의 추가 속도 변화3m/s 상한을 적용한다.20kg은30N·s,2kg은6N·s로 제한됐다.
- 기존 이동 관성을 유지하며 현재 전방과 위쪽0.35의 비율로 던진다. 가벼운 대상과 무거운 대상의 반응을 같게 만들지 않는다.
- 들기 요청 없음·너무 이른 시점·메뉴·Reset·대상 상실·손 제어권 상실은 던지기를 승인하지 않는다.
- 정상/강제 해제에서 추가 Throw impulse를 합성하지 않는다. 양손·중복 요청으로 같은 대상을 두 번 던지지 않는다.
- 오래된 release가 새 Grab을 던지는 데 사용되지 않도록 순수 상태의 release admission 검사도 추가했다.

이 수치들은 START이며 최종 조작감·밸런스 확정값이 아니다.
Throw는 물리 impulse와 들기/복귀 pose까지 연결한 단계이며 전용 throw swing·연출 polish는 후속이다.

## 모델과 pose

처음14cm 들기에서는 어깨 표면 꺾임이 발견됐다.10cm 들기 궤적으로 조정하고,
들 때 clavicle이 전방으로 움직이며 팔꿈치가 조금 바깥쪽으로 벌어지도록 했다.
최대 clavicle 방향은 약32°, 들기 때의 바깥쪽 elbow pole 가중치는0.2 START다.
물리 접촉점을 읽기 전용으로 따라가며 원본 mesh·weight·리그는 수정하지 않았다.
기존 들지 않는 Grab은 기존9° shoulder pose와 기존 팔 궤적을 유지한다.

## 검증 범위

16조건: 들기/내리기, 좌우 던지기, 양손 단일 던지기, 나중에 두 번째 손 추가,
보통 놓기, 준비 전 요청, 메뉴/Reset/대상 상실/소유권 상실, 천장,2kg/100kg 하중,
Presentation 없는 실행, 이동 관성을 유지한 던지기.

- 20kg 표적의 실제 들림 약10.0cm. 천장 조건에서는 약8.0cm에서 더 들지 않았다.
- 던지기는 좌우·양손 모두 해당 요청당1회. 메뉴·Reset·강제 상실과 너무 이른 요청에서는0회.
- 100kg 대상은 들기 중 그립을 잃어 해당 던지기 요청을 실행하지 않았다. 무거운 대상의 무제한 들기를 허용하지 않는다.
- 이동 후 던지기의 최종 전방 z 변위가 정지 던지기보다 컸다. 이 값은 검사 구간의 z 변위이며 비행거리 전체가 아니다.
- Presentation 적용 여부에 따른 물리 결과 차이는 허용값0.1mm 이내였다.
- 4개 주요 동작의184표면 표본에서 인접 면45° 이상 꺾임0·90° 이상 뒤집힘0.
  비인접 자기 교차 전수 검사나 모든 상황의 자연스러움 보장은 아니다.
- 손끝-접촉점 오차는 수치 오차 수준, 팔 도달 길이 보정0이었다.

## 남은 사용자 결정

권장안은 **잡은 채 Ctrl을 누르면 들고, 들어 올린 뒤 Ctrl을 유지하며 손 버튼을 놓으면 던지기**다.
Ctrl 없이 놓으면 기존처럼 그냥 놓는다. 제시한 대안은 같은 대상을 양손으로 잡을 때 자동으로 드는 방식이다.
답변을 받은 뒤 입력 연결과 그 입력을 통한 회귀 검사를 진행한다. 현재 영상은 테스트가 명시적인 물리 명령을 호출한 결과다.
