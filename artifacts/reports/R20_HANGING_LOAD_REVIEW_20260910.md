# R20 한손·양손 매달림 하중 반응 — 2026-09-10

상태: **로컬 시제품 반영·체감 확인 대기**. 사용자가 벽 잡기의 딱딱함을 지적하고 한 팔/양팔에 중력이 작용할 때의 자세 차이를 요청했다. 기본 정적 가장자리 장면에 실제 지지력에 반응하는 절차적 자세를 추가했다.

## 달라진 동작

| 상태 | 표현 |
|---|---|
| 왼손/오른손만 지지 | 잡은 어깨를 기준으로 골반이 해당 손 아래로 기울며, 비어 있는 팔과 다리는 몸통보다 수직 방향에 가깝게 처진다. 좌우는 대칭이다. |
| 양손 지지 | 가운데로 처지고 양손의 실제 하중 차이가 있을 때만 작은 기울기가 생긴다. |
| 한손↔양손 | 하중·기울기·골반 처짐·지지 중심을 감쇠해 연결한다. |
| 놓기/상승/착지 | 하중이 줄면 원래 공중/착지 자세로 돌아간다. |
| 넉다운/초기화 | 매달림 자세의 누적 상태를 지우고 기존 레그돌/초기화 경로로 넘긴다. |

정지 평형에서 한손 기울기 목표는8도, 골반 수직 offset은0.025CU이고 양손은0.035CU다. 한손은 어깨를 축으로 기울면서 골반의 실제 높이·위치도 함께 바뀌므로 offset 수치만으로 두 자세의 처짐을 비교하지 않는다. 양손의 불균등 하중 기울기는 최대4도 START다. 고정60Hz에서 실제 지지 하중/체중과 속도를 읽으며 임의의 반복 흔들림은 넣지 않았다.

`HangingBodyPose`가 표시 bone을 조정하고 `GrabArmPose`가 손 접촉을 다시 맞춘다. 몸이 기울었을 때 팔꿈치 굽힘 방향도 몸통 기준을 따르도록 바꿔 어깨 비틀림을 줄였다. 팔의 도달 한계에 가까우면 자세 변형량을 줄이며 bone 길이를 늘리지 않는다.

## 물리와 판정

- 한손당 기존 spring/damping·최대 지지력, GripStress, 클릭 유지, Space 보조2회/350ms, 재잡기와 도달 판정은 유지한다.
- 지지력은 기존 물리 계산에서 읽는다. 이 변경은 전체 관절로 매달림을 푸는 새 물리 solver가 아니라 실제 하중을 따르는 자세 표현이다.
- 도달 판정은 추가 자세 이전의 고정 시점 팔 위치를 보존해 사용한다. 자세가 바뀌었다는 이유로 손이 더 멀리 닿거나 복귀 높이가 달라지지 않게 한다.
- 타격용 별도 rig도 같은 하중 상태를 사용한다. 해당 tick의 물리 후 자세가 완성되면 이후 query는 그 저장된 자세를 사용한다. 렌더 보간 bone은 판정에서 읽지 않는다.
- 매달리지 않을 때는 기존 자세를 그대로 통과시킨다. 공중 tap으로 지상 펀치를 새로 허용하지 않으며 기존 Air 입력 정책은 유지한다.
- 원본 모델·리그·weight·승인 clip 파일은 수정하지 않았다.

## 확인 절차와 결과

1. `Project Hotfix > Prototypes > Open Shared Arena 2/3/4 Players` 또는 `Open Ledge Recovery Review`를 연다.
2. 정적 벽의 손이 닿는 지점에서 좌/우 클릭을 유지한다. 한 손→양손→한 손으로 바꿔 몸통과 골반 반응을 본다.
3. Space로 복귀하거나 클릭을 놓는다. R 초기화와 넉다운에서도 이전 매달림 자세가 남지 않는지 확인한다.

자동 검토는 실제 표면 query로 접촉을 만들고, 낙하 시작값과 입력만 검토용으로 제공한다. 모델을 손 위치로 순간 이동시켜 매달린 것처럼 촬영하지 않는다.

- 왼손/오른손/양손 각각의 수정 전후 비교에서 Root 위치·속도, 잡기/해제/보조 상태가 같았다. 비교 영상의 각180개 고정 tick에서도 위치와 잡힌 손이 동일했다.
- 한손↔양손→놓기에서15/60/144FPS 상당의 렌더 일정에 따른 bone 위치 차이는0이었다. 기존4방향×3깊이 복귀와 두 번의 보조 제한도 재검증했다.
- 손 접촉 오차는 측정 시나리오에서0.001mm 미만, 물리 후 타격 rig와 저장된 표시 자세의 위치 오차도0.001mm 미만이었다. 매달림/전환 표면의 인접 삼각형 각 최댓값은 약50.17도였다. 이 동작의 로컬 급격한 접힘 회귀 기준은60도이며 기존 보행 검토의45도 기준을 바꾸지 않았다. 이 수치는 자체 교차 전체를 보증하는 검사는 아니다.
- 초기 큰 기울기와 월드 수직 팔꿈치 기준에서 나온 어깨 접힘은 몸통 기준의 굽힘 방향과8도 기울기로 수정했다.
