# 다음 로컬 단계: 펀치 피격 → 넉다운 → 회복 연결

후속 사용자 최종 결정으로 **타격 임계값 감소를 폐기**했다. 현재 규칙은 [고정 타격·무력 Down](R20_FIXED_HIT_LIMP_DOWN_REVIEW_20260908.md)이다. 아래5→4→3→2와 검사는 당시 비교 이력으로 보존하며 현재 기본값이 아니다.


상태: **사용자 답변 반영, 구현·검증은 [후속 기록](R20_HIT_DOWN_INTEGRATION_REVIEW_20260908.md)에서 추적**.

사용자 결정: 시간 감소 없이 계속 누적하고, Down 중 재피격은 impulse만 적용한다. 기존 제안의 자연 감소는 채택하지 않는다. 추가로 DownCount가 높을수록 다음 Down에 필요한 타격 수를 줄인다. 아래 표는 질문 당시의 제안 이력이며 현재 규칙을 대신하지 않는다.

2026-09-08 사용자는 골반·하체 회복 수정 뒤 다음 계획 진행을 요청했다. 현재 회복안을 후속 로컬 작업의 입력으로 사용한다. 이 진행 지시를 정식 캐릭터/네트워크/Alpha Gate 전체 승인으로 확대하지 않는다.

## 확인된 현재 경계

- `HandStrikeReview`는 실제 물리 sweep·벽 가림·공격별 대상 중복 방지 뒤 `StrikeReviewTarget.ConfirmHit`를 호출한다. 현재 결과는 적중 기록과 bounded impulse다.
- `StrikeReviewTarget`에는 피해 누적이나 자동 Down 연결이 없다. `LastActionId`만 저장하므로 다인 연결에서 이를 전역적으로 유일한 공격 ID로 사용하면 안 된다.
- `RagdollRecoveryReview.BeginDown`은 검토용 명령으로 넉다운을 시작한다. 이후 무력 래그돌, 실제 지지/공간 판정, 앞뒤/측면 회복, 최신 골반·하체 GetUp, 이동 복귀가 연결되어 있다.
- 래그돌 보조 body는 actor 외부의 별도 계층에 있다. 피격을 연결할 때 각 collider가 어느 캐릭터에 속하는지 명시적으로 매핑해야 한다. 단순 `GetComponentInParent<StrikeReviewTarget>`만으로 모든 팔다리를 판정할 수 없다.
- 던진 뒤 벽·바닥·일반 물체/캐릭터에 닿는 일반 충돌은 추가 Damage·피해 누적 0이다. 충돌 callback을 자동 피격으로 연결하지 않는다.

## 먼저 결정할 정책

| 항목 | 제안 | 상태 |
|---|---|---|
| 일반 펀치 피격 | 연속 유효 피격에 넉다운 수치를 누적하고, 비피격 시간이 지나면 서서히 감소 | 사용자 답변 대기 |
| 이미 Down인 대상의 추가 피격 | 물리 밀어내기만 적용하고 누적/새 episode/회복 대기 연장 0 | 사용자 답변 대기 |

이는 약한 공격과 강한 공격의 구체적인 피해표, 무기 공격, Kick/Dropkick, 일반 충돌의 피해 없는 물리 Down을 승인하는 질문이 아니다. 해당 범위는 이번 연결에 넣지 않는다.

정책 승인 뒤 검토용 profile의 펀치 누적량·임계값·감소 대기/속도를 분리한다. 정확한 값은 비교를 위한 START로 명시하고 최종 밸런스로 고정하지 않는다. 기존 DownCount에 따른 Base/Increment/Max 규칙과 현재 GetUp 길이는 유지한다.

## 구현할 결과

1. 승인된 피격 정책을 Unity 참조 없는 Simulation 상태로 구현한다. 공격자/공격 action/대상과 reset 세대를 구분하고 동일 hit의 중복 처리를 막는다.
2. 로컬 권한이 확인한 Punch hit만 누적 상태에 전달한다. 임계 도달의 새 Down에서 기존 `BeginDown`을 한 번 호출한다. 적중 impulse와 Down 시작 impulse를 중복 적용하지 않는다.
3. actor와 래그돌 팔다리 collider의 소유자를 명시적으로 연결한다. 자기 타격·벽 뒤 타격·복수 collider 중복을 방지한다.
4. 기존 타격 표적 검토는 유지하고, 실제 캐릭터를 대상으로 펀치→Down→회복→이동을 확인하는 로컬 검토 장면을 제공한다. Player Build는 실행하지 않는다.

## 검증 체크리스트

- [ ] 좌/우·양손·서로 다른 공격자의 유효 피격을 구분한다.
- [ ] 벽 뒤·거리 밖·자기 자신·비활성 대상은 누적/Down 0이다.
- [ ] 같은 action의 여러 collider 또는 여러 physics step 적중은 1회다.
- [ ] 선택한 누적/감소 경계와 임계 도달을 검사한다.
- [ ] 같은 Down episode에서 추가 피격이 선택한 시간 정책만 따른다. DownCount는 중복 증가하지 않는다.
- [ ] 던진 뒤 벽→바닥→재충돌에서 추가 Damage/누적/자동 Down 0이다.
- [ ] Grab 중 Down 시 본인 손은 추가 Throw 없이 해제된다.
- [ ] Reset/권한 해제/메뉴 재무장과 새 episode에서 오래된 입력·피격을 재사용하지 않는다.
- [ ] 최신 회복 동작, 기립 후 흔들림 보정과 즉시 이동을 회귀 검사한다.
- [ ] 실제 렌더 비교와 검사 결과를 보존한다. 합성 피격 주입만으로 실제 전투 연결을 완료 처리하지 않는다.

위 체크리스트는 이후 구현의 완료 조건이며 이번 준비 단계에서 실행한 검사 결과가 아니다.
